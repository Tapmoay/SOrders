# 司机分类计费改造 — 业务计划 v2（评审后修订版）

> 修订说明：已采纳子代理评审全部 A/B/C/D 结论。评审发现的最关键现实问题：**现有 API 已把货款（商品单价/小计）返回给司机端**（enrich_order_out 未做角色过滤），只是 UI 没渲染——本轮必须一并堵上。

## 1. 需求原文
1. 司机分三种：小车、大车、挂车司机。
2. 小车/大车司机拿固定工资，接单时不能看到订单金额。
3. 挂车司机按单量计费，可以看到每个单多少钱。
4. 挂车司机看到的钱不是货主货款，而是"该订单的价格"（运费），由派单员指定。
5. 派单员可以构建订单模板，方便选择。
6. 挂车计价方式：A 地到 B 地，多少钱一车。

## 2. 现状事实
- users 无司机类型；orders 无运费；金额仅存在于订单明细（货款）；派单接口只传 driver_id；司机端 UI 不显示金额。
- **评审证实**：enrich_order_out 对司机返回的 OrderOut 含 order_products（unit_price/line_total 货款）→ API 层已漏货款。
- 订单状态机 5 态：PENDING_DISPATCH / DISPATCHED(已派未接) / ACCEPTED(已接/配送中) / DELIVERED / CANCELLED。

## 3. 关键业务决策（评审定论）
1. **运费后补**：派单时可留空，司机端显示"运费待定"；不卡派单流程。
2. **批量派单不做统一运费**：全部走订单详情补录（各单价格常不同）。
3. **模板车型仅提示不强拦**：模板是快捷价，不是资质校验。
4. **"本月运费合计"纳入 P1**（司机端 + 派单员侧结算视图，按单计费的闭环）。
5. **计费纪律**：只对 status=DELIVERED 且 freight_fee 非空的订单计费；撤销/撤回/已派未接一律不计、司机端标注"不结算"。
6. **司机换类型保护**：订单冗余快照 driver_billing_mode_snapshot（派单时写入），可见性按快照判定；老订单（无快照）回退用司机当前类型。
7. **运费与货主结账隔离**：不进货主 ledger；新增派单员侧"司机运输费结算"视图（按司机×月：已送达计价单+合计）。
8. **改费窗口**：DELIVERED/CANCELLED 之前可改（含 DISPATCHED/ACCEPTED）；改费记审计（旧值→新值）；改价后给按单司机推"运费更新"通知。
9. **UI 简化**：司机管理只暴露"车型"一个入口，计费方式自动推导（挂车→按单，其余→固定工资），字段落库，高级例外后续再说。
10. **序列化统一门控**（最高优先）：所有司机剥离货款；运费仅 piece 司机可见；列表/详情/WS 推送/通知全部共用同一门控函数。

## 4. 数据模型
- users + vehicle_type（small/large/trailer/空）+ billing_mode（salary/piece，自动推导可独立存）。
- orders + freight_fee（Numeric(12,2) 可空）+ driver_billing_mode_snapshot（str 可空）。
- 新表 freight_templates：name/from_place/to_place/vehicle_type(可空=通用)/fee/remark/created_by/时间戳。

## 5. 界面清单
### 派单员
1. 司机管理：创建/编辑加"车型"选择器（小车/大车/挂车），列表显示车型标签。
2. 工作台「派单作业」新增"订单模板"：列表/新建/编辑/删除。
3. 待派单池（单票派单）：选司机后，若按单计费 → 显示"运费"输入 + "从模板选择"按钮。
4. 订单详情：运费展示 + 补录/修改运费（送达前），审计留痕。
5. 新增"司机运费结算"视图（按司机×月，已送达计价单+合计）。

### 司机
1. 挂车司机：订单卡/详情显示"运费 ¥xxx"（未定="运费待定"）；撤回/撤销单标注"不结算"。
2. 固定工资司机：任何通道看不到货款与运费（后端强制）。
3. 挂车司机"我的"：本月运费合计卡片 → 运费明细列表。

### 货主：无变化。

## 6. 范围
- **P1**：司机分类、freight_fee+快照、序列化与推送门控（含剥离已漏货款）、派单指定运费、模板 CRUD+选价、补录/改费+审计+改价通知、司机端运费显示与本月合计、派单员侧结算视图。
- **P2**：模板车型强校验、运费明细导出、报表运费维度、固定工资工资单、freight_remark（含装卸）、司机车辆档案。

## 7. 兼容
- 老司机无车型 → 按固定工资（billing_mode 缺省 salary），看不到任何金额，行为与现状一致（但货款剥离是行为变化——司机端 UI 本就未渲染货款，无感知）。
- 老订单 freight_fee=null → 挂车司机"运费待定"，派单员可补录。
- 模板表新建，零迁移风险。
