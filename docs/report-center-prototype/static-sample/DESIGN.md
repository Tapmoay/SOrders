# 报表中心 → 仪表盘：改版样板（v2）

> 这份文件的用途：把「现在 11 张平铺卡片」改成「一页能看懂的仪表盘」这件事，先做成一个**完全独立**的样板把样子定下来。
> 样板是**编的数据**，不连后端、不动 App 任何代码。位置：`_tmp/dashboard_proto/index.html`（浏览器直接打开；手机宽度 420×940）。

## 一、三层信息结构（这就是「重要 / 不重要」的分档）

| 层级 | 内容 | 什么时候看 |
|---|---|---|
| **第一层：仪表盘**（打开就在这一页） | 营业额 + 毛利（两个大数字）→ **还没收回来的钱**（时点账：¥69,556.80 / 33 人 365 张单 / 四个账龄桶）→ **要处理的事**（钱货风险 / 履约卡住 / 超额度 / 该付司机的钱 + 拖最久的三张异常单）→ 钱（这一段收回来多少、新增挂账多少）→ 赚了多少（小利润表）→ 税 → 走势 | 每天打开就看这一页 |
| **第二层：常用报表**（4 个） | 营业纵览、客户欠款、异常与审计、资金收支 | 每天收工前 / 每周 / 有异常时 |
| **第三层：偶尔才查**（7 个） | 司机绩效、经营利润、商品经营、客户经营、成本覆盖、车辆成本、税账 | 有具体问题时（给司机结账 / 月底看利润 / 毛利看着不对 / 申报前） |

分档依据：后端数据面整理的「每天必看 vs 偶尔才查」归纳（营业额、单量、已收+挂账、欠款账龄、异常、司机待结运费属每天必看）。**后端代码里没有这个定义**，是我们照数据口径归纳的，所以样板把它写成了界面上的标签，而不是藏起来。

## 三、相对现在 App 的改动（每一条都能指出为什么要改）

1. **首屏从「11 张卡片」变成「先给结论」**：营业额/毛利 → 欠款 → 要处理的事。卡片挪到最下面，还分了两档。
2. **时点账和区间账分开，各自写明**：累计欠着的 ¥69,556.80 是**到今天为止**的时点账；「钱·这一段」里的营业额/已收/新增挂账是**这一段**的区间账。样板把这两个标签直接印在卡上——现在 App 里两者混在一页，容易被读成同一件事。
3. **窗口标签跟着数字走**：顶部药丸今天/本周/本月/上月（默认今天），每张卡右上角写着这一段是什么（`10-04` / `09-29 ~ 10-04`）。子页也带同一套窗口药丸，切窗口不用退回首页。
4. **页内能换页签**：子页顶部有一条可横滑的页签条（现在 App 的 11 个页签是 11 条独立路由，对比两张报表必须退回卡片页）。
5. **「已过去」单独沉底**：119 单逾期送达/已撤销不再和「要处理的事」混在一起，灰字放底下并写明理由。
6. **颜色一处定义、语义固定**：入口卡图标色 = 页面里那个大数字的颜色；绿=赚/收、橙红=欠、红=险、灰=已过去/不用管。现在 App 里同一个「营业」在入口是橙色、页内是蓝色，车辆成本合计用了危险红。
7. **司机绩效页原来一个大数字都没有**（现在 App 的 DriverTab 里 0 个 StatBig）→ 样板把「该付司机的钱」做成大数字，逐司机列出还没结的运费。
8. **口径句常显，不放提示里**：钱的口径（未收款不让营业额变小、司机运费按「按单应付」不是订单上那个字段、成本三级、准时率没样本给 null 不是 0）在样板里都是常显的一行小字，不藏在「提示」按钮后面（关掉提示会连金额一起关掉）。
9. **走势图用同一把尺子**：蓝=营业额、绿=毛利，都从 0 起算，所以毛利柱矮是真实的；卡里写明这一点（现在是数字直接标在柱子上、比例悬殊会被误读）。
10. **金额一律两位小数、逐行能对上**：四桶之和 = 该收的钱；参与毛利的收入 − 商品成本 = 商品毛利；毛利率分母写明是「参与毛利的收入」。

## 四、样板里的数字是真自洽（不是随手编的）

四套窗口（今天 / 本周 / 本月 / 上月）的每一个数都满足：

- 毛利 = 参与毛利的收入 − 商品成本（今天 20,480 − 15,690 = 4,790；本周 118,400 − 91,900 = 26,500）
- 营业利润 = 毛利 − 司机运费 − 期间费用 − 车辆折旧（今天 4,790 − 2,980 − 560 − 170 = 1,080）
- 营业额 = 这一段已收 + 这一段新增挂账（今天 17,880 + 4,620 = 22,500）
- 账龄四桶之和 = 该收的钱（28,475.60 + 19,770.90 + 20,535.90 + 774.40 = 69,556.80）
- 应缴增值税 = 销项 − 进项（9,860 − 5,947.60 = 3,912.40）
- 子页的合计也全部跟着这句话走（逐商品金额之和 = 商品总金额，逐司机运费之和 = 司机运费，没成本的货之和 = 营业额 − 参与毛利的收入）

欠款那块用的是**真库真数**（¥69,556.80 / 33 人 / 365 张单 / 三个欠款人），其余是编的。

## 五、待你拍板的几处（样板里已经先按我们的判断做了）

1. 默认窗口用**今天**（原样板是本周）。今天的数据是当天的，看到的是「今天到现在为止」。
2. 「司机待结运费」放在**第一层「要处理的事」**里（它每天必看但很容易忘）。
3. 第二层放 4 个、第三层放 7 个——如果你常看的不是这四个，挪一下就行。
4. 仪表盘不给「刷新」按钮（样板里点了会提示是编的数据）；真实现时按现在 App 的刷新规则来。
