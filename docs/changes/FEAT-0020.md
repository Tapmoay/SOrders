```text
Input          用户那句话（如「给城东水果批发送 3 件红富士苹果到城东大道 1 号」）＋ 模型从话里抽的参数。
```

- **删除本功能后历史数据还能不能解释**：能 —— 工作流不留任何痕迹，AI 流水里记的仍是读/写动作本身。
