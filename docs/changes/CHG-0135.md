# CHG-0135 · 订单详情的「送达日期」按设计规范重做，并且**派单员可以改**

## ① 六问

**① 要解决什么**：用户 2026-10-22（对着详情页截图）：「我们这个订单详情页送达日期……你的设计
**并没有按我们的设计样式**进行设计啊 —— **要有对应的图标和语义色**……而且**我们的派单员是可以修改
这个信息的**」。

**② 当前流程是什么**：那一行只是 `InfoRow("送达日期", …)` —— 没有图标、没有语义色、没有"可改"的形；
派单员看到日子不对，只能去备注里写一句，或者让货主撤销重下。

**③ 哪个事实会变**：`OrderUpdate` 多一个 `delivery_date`（派单员可改，货主那扇门撞到它 403）；
审计 payload 的 `DISPATCHER_TRACKED_FIELDS` 从 3 项变 4 项（**有意的形状变化** —— 不改的话
"谁把日期改了"在日志里查不到）。

**④ 明确不能变**：
- ⛔ `order_date`（哪天下的单）与 `expected_deliver_before`（SLO 截止时刻）的语义；
- ⛔ 钱 / 状态机 / 账本 / 库存 / 通知；
- ⛔ 货主那一扇门（`PATCH /orders/{id}/contact`）仍然只能补那四个联系字段；
- ⛔ 早于今天的日期一律拒（与下单同一条口径）；
- ⛔ 只读的人（货主 / 批发商 / 司机）看不到竖杠与铅笔。

**⑤ Core / Extension**：**PRESENTATION + 既有 PATCH 上的一个字段**（L2：契约与审计形状变了）。

**⑥ 证据**：判据 51 项、反验 24 条、单测 132 类 / 1815 条、两张真机截图（那一行 / 改日期块）。

## ② Must Change / Must Not Change

```text
Must Change:
- 详情页那一行：竖杠（可改）＋ 日历图标 ＋ 语义色 ＋ 铅笔（EditHint）
- 派单员可改：OrderUpdate 收 delivery_date → PATCH /orders/{id} → 库里真的变
- DeliveryDateEditBlock：M3 日历，选择层封顶今天（复用 deliveryDateSelectable）
- 审计：DISPATCHER_TRACKED_FIELDS 增 delivery_date（谁改的、改成哪天，日志里查得到）

Must Not Change:
- ⛔ order_date / expected_deliver_before 的语义；⛔ 钱 / 状态 / 账本 / 库存
- ⛔ 货主那扇门只能补四个联系字段（多报一个就 403）
- ⛔ 早于今天一律拒
- ⛔ 只读角色不给竖杠与铅笔
```

## ④ Behavior Contract

```text
Input          派单员在详情页那一行点铅笔 → 选日期 → 「保存送达日期」（PATCH /orders/{id}）
Output         orders.delivery_date 真的变；审计多一条 ORDER_UPDATE（before/after 含 delivery_date）
Success        弹一句「已经改好，司机那边会收到一条消息」（既有的改单回执）
Failure        选到早于今天 ⇒ 400「送达日期不能早于今天」；货主那扇门多报 ⇒ 403
Boundary Cases · 空串（老单没选过）= null = "不给就不改"（⛔ 不用它清空已有日期）
               · 终态单（已送达/已撤销/已退货）不可改 —— 走既有的状态门
               · 非派单员看不到铅笔（竖杠同理）
Side Effects   订单编辑事件照旧推给司机（orders.edited）—— 日期变了，司机该知道
Authorization  `order:edit`（沿用既有），不新建权限点
Compatibility  兼容：新增**可空**入参；老客户端不传 = 不改
```

## ⑤ Data Contract

- **新增/改动哪些字段**：`OrderUpdate.delivery_date`（可空，None = 不改）。
- **Owner**：订单表；写入口仍是 `commands/order.py::update_order`。
- **什么时候写**：派单员保存那一格时；⛔ 其余路径不写。
- **是否允许 NULL**：允许（老单没选过）；⛔ 本轮不支持"清空成未选择"。
- **历史数据怎么办**：不动。
- **迁移 / Rollback**：无迁移；回滚 = 撤掉界面那一格的铅笔与 OrderUpdate 里那一个字段。
- **删除本功能后历史数据还能不能解释**：能（列还在）。

## ⑥ CHG 专章

### Before

- 详情页：`送达日期　10-23 · 还有 1 天` —— 一行灰字，**没有图标、没有语义色**，
  与上下那些「收货人 / 下单人（带图标、带色、带竖杠与铅笔）」不是一个样子；
- 派单员想改日期：**改不了**（那一格从来不可编辑）。

### After

- 同一行：**竖杠 ＋ 日历图标（浅蓝底）＋「送达日期　10-23 · 还有 1 天」＋ 铅笔**，
  与同页其它可改行同一套形（CHG-0125 定下的"竖杠＝这格能改"）；
- 点铅笔 → 那一行就地变成「送达日期　10-23 · 还有 1 天　[选日期]」＋ 取消／保存送达日期；
  日历选择层封顶今天；保存走同一条 PATCH，司机收到 `orders.edited`。

### Must Preserve

```text
- order_date / expected_deliver_before 的语义
- 货主那扇门只能补四个联系字段
- 早于今天一律拒
- 只读角色看不到竖杠与铅笔
```

### Blast Radius（L0～L3）

**L2**：新增一个可改字段（入参 + 审计形状 + 权限分界线），走兼容性与反向验证。
