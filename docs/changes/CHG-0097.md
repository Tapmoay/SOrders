## ③ Boundary（Core / Extension / Infrastructure / Presentation）

- **结论**：**PRESENTATION**（`ui/ai/AiChatScreen.kt` 的 `ExportFileRow` 里那一行字）＋ **EXTENSION IMPL**（`ai/AiExportCard.kt` 新增 `exportSavedLabel` / `exportStatusLine` 两个纯函数，不 import android.\*）。
- **为什么不是 Core**：Core 是订单/账本/钱的规则。这里改的是"卡片上写几个字"，删掉这行字，订单、账本、结算、导出结果**一个字节都不变**。
- **为什么不是 Infrastructure**：没碰数据库、端点、权限、任务队列、落盘路径。
- **为什么不是"数据契约"**：`StoredExportRecipe` 的键名、`ExportRowState` 的字段、`ExportedFile.path` 的值**都没动**；动的只是"把 `path` 显示成什么"。⚠️ `path` 这个字段本身**照旧存在、照旧落盘**，只是界面上不再显示它。
- **为什么新建纯函数而不是就地改字符串**：用户点名的就是"这句话的长短"。留在 Composable 里，判据只能靠正则去源码里找字符串；抽成纯函数之后，`AiExportCardTest` 能直接断言「存好那一档的结果里**不含** `/storage`」—— 这才是"下次有人手滑把路径加回来"能立刻报红的那种判据。

## ④ Behavior Contract

```text
Input:
  - error: String          这一条消息取件失败时的原话（空＝没失败过）
  - saved: Boolean         文件已经在手机上了
  - busy: Boolean          此刻正在取件
  - progress: String       取件过程中后端报的那句（账本才报，如「已等 8 秒」）
  - recipe / state.file    照旧来自 ExportFileRow 的入参（签名未变）

Output:
  - exportSavedLabel()  -> "已保存"
  - exportStatusLine(...) -> 一行字，且**不含文件路径**

Success:
  - 存好之后卡片上只出现「已保存」三个字，那一行只有一行高

Failure:
  - 取件失败时这一行是 "⚠ " + error，且用 colorScheme.error 上色（压过「已保存」）

Boundary:
  - 什么都没发生时这一行是空串 ⇒ 界面不画它（不留一条空行）
  - error 与 saved 同时为真时：error 赢（顺序即判据）

Side Effect:
  - 无。两个纯函数不碰文件、不发网络、不写盘

Authorization:
  - 不适用：不改任何权限判定（分享那颗的可用性仍由 exportCardActions 说了算）

Compatibility:
  - 导出链路、落盘位置、分享行为逐字未变；老消息的 exportRecipe 照旧能渲染
```

## ⑥ CHG 专章

### Before

```kotlin
val note = when {
    state.error.isNotBlank() -> "⚠ " + state.error
    saved != null -> "已保存到：" + saved.path          // ← 一整条 /storage/emulated/0/… 摊在卡片上
    else -> exportProgressNote(...)
}
Text(note, maxLines = 2, ...)                            // ← 两行，把卡片撑成一大块
```

真机上那一行长这样（用户截图圈的就是它）：

```text
已保存到： /storage/
emulated/0/Download/…
```

### After

```kotlin
// ai/AiExportCard.kt（纯函数）
internal fun exportSavedLabel(): String = "已保存"

internal fun exportStatusLine(error: String, saved: Boolean, busy: Boolean, progress: String): String = when {
    error.isNotBlank() -> "⚠ " + error
    saved -> exportSavedLabel()
    else -> exportProgressNote(busy = busy, saved = false, progress = progress)
}
```

```kotlin
// ui/ai/AiChatScreen.kt —— 界面只管画
val note = exportStatusLine(
    error = state.error,
    saved = saved != null,
    busy = state.busy,
    progress = state.progress,
)
Text(note, maxLines = 1, overflow = TextOverflow.Ellipsis, ...)
```

卡片上那一行现在是：

```text
已保存  ✓
```

### Must Preserve

- 失败那一档：`"⚠ " + error` 原样（且用错误色）—— 「说一句实话」永远压过"看起来一切正常"；
- 忙那一档：账本报的进度原样（如「已等 8 秒」），没话说时有「正在生成…」顶上去；
- Android 10 以下那句中文说明（`"这台手机（Android 10 以下）…"`）一个字不动 —— 它是**唯一**还写着文件位置的地方，而它只在"分享不了"这一档出现（那时用户确实需要知道去哪儿找）；
- 左框与右两颗按钮：尺寸、语义色、12dp 间距、"两颗永远都在"全部不动。

### Blast Radius

**L0 —— 展示层**：只改"这行字写什么"和它占几行。读的三样输入、两个回调签名、落盘与分享的每一步都没动。
