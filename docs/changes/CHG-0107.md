## ① 六问

**用户口径**（逐字，ref **m00711**）：

> 「呃把整体的样式再调鲜艳一点感觉还是有点灰啊啊。这次快一点啊，因为我们只是调个颜色」

前置口径（CHG-0105，ref **m06201**，逐字）：「同样是按照我们一开始调整工作台的那种色彩理论嘛……来调整它们的明度或者说是饱和度，但是**不要调整，它们的色相**啊」。

⇒ 一句话：**色相一个都不许挪，明度 L\* 也一个都不许挪，只把彩度 C\* 整体抬上去。**

## ② Must Change / Must Not Change

| Must Change | Must Not Change |
|---|---|
| 全 App 有颜色的那些 token 与裸字面量的 **C\***（×1.45） | **色相 h**（一处不动 —— 这是 CHG-0105 刚还回来的东西） |
| 设计系统 §2 的总表、登记簿、各判据里钉住的期望值 | **明度 L\***（`L* 58±5` 那条带子原样保留） |
| — | 近中性的底与分隔（`BackgroundLight` / `SurfaceContainer*` / `Outline*`，C\* < 6 一律不碰） |
| — | **AI 品牌那几颗**（见 ④） |

## ③ Boundary

**PRESENTATION（展示层）** —— 只改 `ui/theme/Color.kt` 的数值、`android/**` 里硬编码的同一批色值，以及随动的判据与文书。路由 / 能力 / 权限 / 账本口径 / 数据库 / 历史数据一处未动。

## ④ CHG 专章：算法与两条例外

```text
新值 = LCh2sRGB( L* 原样, min(C* × 1.45, 该 L*/h 下的色域上限 × 0.96), h 原样 )
```

- 基线取 `git HEAD`（CHG-0105 落盘后那一版），因此**可重复跑**：已经改过的不再匹配（`_tmp/chg0106_vivid2.py`）。
- 近中性色（C\* < 6）不参与 —— 硬套只会给白底与灰线引入取整噪声（沿用 CHG-0105 的 `MIN_CHROMA` 判断）。
- **为什么提彩度不会破坏宫格与判据**：L\*、h 不变而 C\* 乘 k ⇒ Lab 同 L\* 平面上的两点距离整体乘 k（宫格两两距离只会变大）；L\* 极差不变（`DISP_SPREAD` / `SHIP_SPREAD` / `LEDGER_SPREAD` 三条不受影响）；彩度地板只会更容易过。

**例外一：撞「太深/太沉」带子的上界（`_tools/qa/_check_ledger_dashboard.py:392-400`）**

该判据要求网格每格 `44 ≤ max(R,G,B)/255×100 ≤ 88`。提彩度会在 L\* 不变的前提下把最亮的那个通道推高，7 个裸字面量因此越界（`007BE8` 91.0% / `5E98F5` 96.1% / `9B84F5` 96.1% / `E18033` 88.2% / `E64C88` 90.2% / `F16D4F` 94.5% / `F86A77` 97.3%）。做法：保 h 与 L\*，二分把 C\* 收到 max 通道 ≤ 88% 为止（`_tmp/chg0106_cap88.py`）。

**例外二：AI 品牌那几颗不参与（`_tmp/chg0106_brand_back.py`）**

| token | 提彩度后 | 退回 | 为什么 |
|---|---|---|---|
| `AiBlue` | `#0085FF` | `#4285F4` | 用户点名保留的 Google 蓝；提彩度后与「地址与联系人」`#00A4CE` 距离掉到 **57**（下限 60），`ModulesEntryTest` 与 `ThemePaletteTest` 同时红 |
| `AiPurple` / `AiPink` | `#A167EB` / `#F64865` | `#9B72CB` / `#D96570` | AI 品牌三段渐变（`BRAND_EXEMPT_BY_ROUTE = {"ai/chat"}`） |
| `AiChatGreen` / `AiChatGreenDeep` | `#22914F` / `#1B7740` | `#4B8C5E` / `#3D734D` | CHG-0104 定的是「像微信的绿」＋两档白字对比度，`AiChatGreenTest` 钉着彩度带（提到 52.8 判红） |

## ⑤ Behavior Contract

- 每个入口色仍由 `ui/theme/Color.kt` 的 token 或 `ui/nav/Modules.kt` 的裸字面量**一处**说了算（沿用 CHG-0105 的耦合，未新增第二处定义）。
- 宫格两两距离、同屏彩度落差、彩度地板、明度带、白字对比度这五条**全部沿用原阈值**，一个数字都没放宽。
- 白字对比度：L\* 不变 ⇒ 相对亮度不变 ⇒ 登录键（`ThemeGreen`，白字 7.0:1）等处的可读性原样成立。
- `ThemeGreen` / `Primary`：`#28684B` → **`#006C43`**（更深更正的墨绿）。

## 附：这单为什么只有一条规则

用户的要求是「**只是调个颜色**」「快一点」。所以这单**没有引入新机制**：不动色相（CHG-0105 刚还回来的）、不动明度（CHG-0101/0102 定的带子）、不动判据阈值，只把已有的 C\* 乘一个系数，撞到色域或既有带子就回压。留在纸面上的只有两条例外（④），都是「别人已经钉住这颗色」的既有约束，不是这单的新设计。
