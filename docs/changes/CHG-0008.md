## ⓪ 需求方原话（这一批的由来）

>  我们不是有一套完整的设计规范吗？」

③ **哪个现有事实或能力会发生变化？** 见 ⑥ 的 After。
④ **哪些明确不能变化？** 见 ②。
⑤ **属于 Core / Extension / Infrastructure？** **PRESENTATION**，不碰 Core。
⑥ **什么证据能证明完成？** 见 ⑧（真机截图 + 规范条款逐条对读）。
