# CHG-0137 · 冷启动「发现有新版本」提示（同一版只弹一次）

---

- **ID**：`CHG-0137`
- **类型**：CHG（应用内更新）
- **状态**：已关闭（代码 / 判据 / 单测 / 真机走查齐全；⛔ 未发版）
- **Owner**：DSH 主会话（2026-10-26）
- **开工日期**：2026-10-26 ｜ **关闭日期**：2026-10-26
- **Blast Radius**：**L1**（启动时多一次只读请求 + 一个弹窗；⛔ 不动下载/安装链路、不动 version.json 契约）

---

## ① 六问

**① 要解决什么**：用户 2026-10-26：「我们推送的版本，用户第一次打开 App 的时候，还是有一个弹窗
提示说有新的版本了、是否更新？检查一下有没有做」。

**② 当前流程是什么（查证结果：没做）**：`checkUpdate()` 全 App **只有一个调用点**
（`ProfileScreen.kt` 里「我的 → 关于与更新」那一行的 onClick），而那个确认框又挂在**「我的」页内部**。
⇒ 从不点那一行的人，**永远不知道自己该更新**（0.2.19 → 0.2.23 这五版他一次都不会看到）。

**③ 哪个事实会变**：冷启动（登录后）多一次 `GET /api/v1/system/app-version`，有新版本且这一版
**没提示过**时弹确认框；「稍后」会记住这一版。

**④ 明确不能变**：
- ⛔ `version.json` 的字段与语义、判新旧的规则（versionCode 优先）；
- ⛔ 下载 / 安装链路（FileProvider、未知来源开关、进度文案）——只复用，不改；
- ⛔ 手动「关于与更新」的行为（仍然如实报错、仍然能更新）；
- ⛔ 检查失败**不弹任何错误框**（这是顺带的事，不该拦在开门第一秒）。

**⑤ Core / Extension**：**PRESENTATION + INFRASTRUCTURE（一小块偏好）**。

**⑥ 证据**：判据 21 项、单测、模拟器两轮走查（弹一次 / 不再弹）。见 ⑦ ⑧。

---

## ② Must Change / Must Not Change

```text
Must Change:
- 登录后的主界面（RoleHomeScreen）发起一次静默检查（进程内一次）
- 有新版 + 这一版没提示过 → 根层弹确认框（复用同一份 UpdateConfirmDialog）
- 「稍后」/「下载并更新」都记下这一版的 versionCode（同一版只弹一次）

Must Not Change:
- ⛔ version.json 契约与判新旧规则；⛔ 下载/安装链路；⛔ 手动检查的行为
- ⛔ 检查失败不许弹错误框；⛔ 不新增权限
```

## ④ Behavior Contract

```text
Input          冷启动 → 登录成功 → RoleHomeScreen 首次组合
Output         有新版本且这一版未提示过 ⇒ 弹「发现新版本 vX · N」+ 当前版本 + 这一版改了什么
Success        点「下载并更新」= 走原下载链路；点「稍后」= 记住这一版，本次及以后都不再为它弹
Failure        接口失败/超时/解析失败 ⇒ **静默**（不弹、不写记忆、下次冷启动再试）
Boundary Cases · 版本号缺失（老 version.json）⇒ 退回比版本名；构建号 <= 本机 ⇒ 不弹
               · 同一版重发（同 versionCode）⇒ 已记过就不再弹
               · 切 Tab / 转屏 / 回首页 ⇒ 不重复检查（进程内一次）
Side Effects   一次只读 GET；一条 SharedPreferences 记录
Authorization  公开只读接口（与手动检查同一个）
Compatibility  Compatible：不改任何协议
```

### ⚠️ 走查里踩到的一个真坑（写下来省下一个人半小时）

第一轮我造的假版本是 `versionCode=99999999`，**App 没弹** —— 一度以为功能没生效。
真相：构建号是 **10 位日期号**（2026102601 = 20 亿），而 99999999 只有 8 位（1 亿），**它更小**。
⇒ App 当时是对的，是我的假数据造错了。这条已经写成单测用例（`assertTrue(!isNewer(…99999999…))`），
免得下次还有人"看位数"判大小。

- **Environment**：模拟器 `SOrdersD`（5554）；dev 后端；假 version.json 用完即删
- **Timestamp**：2026-10-26 01:1x（Asia/Shanghai）
