# CHG-0036 · 报表中心 v2 三件事：抽屉白话走提示开关、金额列左对齐固定位置、红色只给「欠钱」

> 用户 2026-10-05 在真机上看完抽屉与利润表节点之后（两张截图：抽屉那一行行底下的白话、利润表节点上一条红箭头自上而下贯穿**金额那一列**），原话：
> 「**像这样子的字不要不要**你看，哪个 App 上所有功能上都有字啊。这显然不合理的啊。还有像这样子的**要对齐**啊。
> 呃他那个**金额要左对齐**啊，他有一个一定的位置，其他的也是一样的。还有一点就是**所有文字、所有数字都可以使用其他颜色，
> 但是唯独红色只有也就是这个账他欠了钱才能使用**。还一点就是你这个按钮、你那都那些字，你可以走一个就是我们**开启提示按钮的时候它才会显示**啊，
> 其他的时候就是隐藏 —— 一个就是一个正常软件。包括你也有好多地方都是太多字、太多啰嗦」。

① 三件事：**(a)** 左侧抽屉里 11 个老入口各自挂着一句白话（`REPORT_ENTRY_SUBS`），一个正常 App 不会在每一行底下常驻说明文字 —— 用户要求它**跟着「提示」总开关走**（开启提示才显示，平时隐藏）；
**(b)** 各页的金额是右对齐的，一列数字起点参差不齐（用户截图上那条红箭头画的就是这件事）—— 要求**金额左对齐、有一个固定的位置**；
**(c)** 红颜色被当成了「不好看/亏损」的通用色（亏损的营业利润、负的安全边际率、异常单）—— 用户定：**红色只给「欠钱」**（别人欠我 / 我欠别人 / 超额度）。
② 派单员 → 工作台 → 报表中心（v2 首页 / 各下钻节点 / 左侧抽屉）→ 逐层下钻到订单。
③ 抽屉 11 行的白话改成受 `container.hintPrefs.visible` 控制（默认关 ⇒ 平时看不见，拨开总开关就回来）；
金额列从右对齐改成在同一列宽里左对齐（`LineRow` / `MiniLine` / `TableTile` / `Head` 四处，列宽 `ValueColumn = 104.dp` + 间隔 `ValueGutter = 18.dp`）；
红色语义收口成「只给欠钱」，亏损与异常改用橙色（`Tone.WARN`）；解释型小字（公式、口径、为什么）一并走 Hint。
**数字本身、比率、时点/区间标记、下钻链路、权限、接口一个字都不改**。
④ 钱的口径（页面只取接口字段；唯二的「页面相加」例外仍写在行上）、时点账与区间账不许混加、异常单固定「近 30 天」、
权限 ORDER_DISPATCH、路由与老 11 页、后端零改动、`DatePresets` 既有档位语义、`HintPrefs` 的三条行为（首次登录开一轮 / 冷启动关 / 手拨后不再自动改）。
⑤ PRESENTATION —— 只改展示层的颜色、对齐与显隐策略，不碰任何事实与规则。
⑥ 模拟器 5554 上的同屏截图（红/橙分开、金额列起点一致、抽屉白话默认不见）；把「我的 → 提示」总开关拨开再截一张（白话回来）；
`python _tools/qa/_check_all.py` 全绿；编译通过；文案改动后重跑 `python _tools/qa/_hint_inventory.py --md`。

## ⑥ CHG 专章

### Before

抽屉里 11 个老入口每一行底下都常驻一句白话（「这一段卖了多少、收回多少、还挂多少」…），11 行因此变成 22 行文字；
节点页上公式型小字（「毛利率 = 商品毛利 ÷ 营业额」「商品毛利 ÷ 营业额」…）与口径说明也常显，屏幕上一半是说明；
金额右对齐，一列数字的左边界随字数浮动（¥60.4 与 ¥3743 的起点差出一截，用户截图上的红箭头就是它）；
红颜色被当成「不好看」的通用色：亏损的营业利润、负的安全边际率、异常单的合计与行图标都是红。

### After

同一屏：抽屉默认只剩 11 行「图标 + 名字 + 箭头」（拨开「我的 → 提示」总开关，白话原样回来 —— 见证据里的开关前后两张截图）；
金额列改成固定列宽内左对齐（`ValueColumn = 104.dp` + `ValueGutter = 18.dp`），有箭头的大表头、无箭头的小行、迷你图行都对到同一条竖线；
红色只剩「欠钱」六类（别人欠我 / 我欠司机待结 / 我欠供应商 / 客户欠款 / 司机绩效的待结运费 / 超额度），
亏损与异常改成橙色（`amountTone` 的负数、异常单合计头与行、毛利率与安全边际率为负）；入口格「异常与审计」的图标色也从红改琥珀 `#F5A623`。
公式与口径小字改走 `Hint`（提示总开关关掉时不显示），但**数据/限制类**小字（只画前 40 条、接口按人给/按单给、车没填购置价、异常单固定近 30 天、空态句）照旧常显。
