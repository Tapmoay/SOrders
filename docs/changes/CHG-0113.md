## ① 六问

```text
① 解决什么问题？  用户在真机上圈出「我的」页头部与下方卡片之间那块深色空白，逐字：「把这个我的上面不是有个信息吗？
                  得往下移一点啊，这个中间与下面那个卡片太过于长了，尤其像我们这个账号本身那个中间的信息量本来
                  就比较少一点嘛。所以就防止它导致下面太过于空旷，显得不够美观吧。所以就向下面移一点。」
② 当前流程是什么？ ProfileHeader 资料块的内边距是 top=8dp / bottom=60dp：信息贴在上沿，下面留 60dp 深色空白，
                  司机只有三行资料 ⇒ 卡片上方显得空。
③ 哪个现有事实会变？只有这个头的两处内边距；内容、路由、数据都不变。
④ 哪些明确不能变？ ① 深色背景仍要铺到状态栏下面（只让内容让开）；② 头部**不滚**、白卡 24dp 圆角那套结构不变；
                  ③ 三端共用同一个组件，不许给某一端单开分支。
⑤ 属于哪一层？    Presentation（L0）。
⑥ 什么证据能证明完成？真机（72e5048）装 0.2.13 后「我的」页截图：资料块更靠下、深色留白更短（_tmp/real_profile_after2.png）；
                  `_check_profile_page.py` 54 项仍全过（它钉着"深色头部与状态栏配套""头不滚"这些结构）。
```

## ② Must Change / Must Not Change

```text
Must Change:      android/app/src/main/java/com/tapmoay/sorders/ui/profile/ProfileHeader.kt 的 padding：
                  top 8 → 22、bottom 60 → 40。
Must Not Change:  状态栏让位方式、头部不滚的结构、白卡圆角与整页底色（ProfileHeaderBottom）的呼应关系、
                  三端共用同一组件。
```

## ③ Boundary（Core / Extension / Infrastructure / Presentation）

纯 Presentation：两处内边距。

## ④ Behavior Contract

- 资料块（头像 / 角色标签 / 姓名 / 计费行 / 账号行）整体**下移 14dp**；
- 头部下沿深色留白**从 60dp 收到 40dp**（卡片相应上移、变高）；
- 内容为空（资料还在路上）时照常画，位置一致。

## ⑤ Data Contract

不涉及。

## ⑥ CHG 专章

### Before

信息贴上沿、下面 60dp 深色空白 —— 三行资料（司机/货主常见）时上半屏显得空。

### After

信息下移、留白收紧，视觉重心落在资料与卡片交界处，卡片更早开始。

### Must Preserve

深色背景铺到状态栏下面（时间/电量可见）、头部不随内容滚动、白卡 24dp 圆角。

### Blast Radius（L0～L3）

**L0**：三端「我的」页的头部留白。
