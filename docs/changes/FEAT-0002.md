## ① 六问

① **解决什么问题？** 「共享地点」是全库共用的（本机 64 条，**全部有坐标**），但选择列表
**不按距离排** —— 用户要的是"我附近的那几个先出来"。

② **当前用户 / 业务流程是什么？** 下单时打开「地址库 → 共享地点」，现在按 id 顺序列出全库地点，
用户得自己一个个看名字找。

③ **哪个现有事实或能力会发生变化？** 共享地点列表的**顺序**（内容一条不变）。

④ **哪些明确不能变化？** 见 ② 节。

⑤ **属于 Core、Extension 还是 Infrastructure？** **PRESENTATION**：五问全否
（不定义事实、不改不变量、删掉 Core 照常）。落在后端查询里，所以算 L1。

⑥ **什么证据能够证明它完成？** 判据（分档边界逐档断言）+ 反向验证 + 真机列表顺序。
