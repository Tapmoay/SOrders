## ① 六问

① **我要解决什么问题？** `python _tools/ai/_gen_ai_toolmap.py --check` ⇒
「⚠️ 缺中文名的模块：`['devices']`」（exit 1）。

② **现在是什么样 / 为什么现在不行？** `devices` 是 `FEAT-0018` 新加的端点模块
（`backend/app/api/v1/devices.py`，prefix `/devices`，`POST /api/v1/devices/register` ——
App 首次启动拿本机 `install_id` 换服务端签名那一次）。它在**人工维护**的 `MODULE_CN`
（`_tools/ai/_gen_ai_toolmap.py:57-158`）里没有中文名 ⇒ 生成器每次 `--check` 都报它。

③ **改成什么样？** 按同一张表里 `ai_operations` 那一条的**既有做法**补
` "devices": "设备登记" ` 并写明：**它不是 App 里的一页**（所以这个中文名不是"入口名"，
只为让表完整 —— "永远红的检查 = 没有检查"）。⛔ 读写两侧都不给模型的理由分别在
`_read_coverage.py` / `_write_coverage.py` 的 `EXCLUDED` 里（`_write_coverage.py:305-325`
已登记三条「只能由人做」的理由），本事项**不改那个口径**。
顺带把四份生成物重跑齐（`_check_generated_freshness.py` 要求产物指纹与源码一致）：
`python _tools/ai/_gen_ai_toolmap.py --out-dir docs/ai`（`docs/ai/ai_toolmap.json`、`docs/ai/kb_skeleton.md`）、
`python _tools/ai/_gen_ai_read_catalog.py`（`docs/ai/ai_read_catalog.json`，它的真源里含 `ai_toolmap.json`）、
`cd backend && python -m scripts.gen_endpoint_index --out ../docs/PROJECT_MAP/08A_ENDPOINT_INDEX.md` ——
后两份是被**今天两单已提交的**后端改动顶过期的（`FEAT-0018` 的 devices 端点、`FEAT-0019` 的
notifications severity，见 `3fc4f91c`），不是语义变更。

④ **哪些东西明确不能变化？** ⛔ 不给 AI 开 `devices` 的读写（那是另一件事，要走 `EXCLUDED` 的口径讨论）；
⛔ 不改 `POST /api/v1/devices/register` 的行为；⛔ 不改生成器逻辑（只补表里的一行）；
⛔ 不去手改生成物（必须由生成器重跑出来）。

⑤ **属于 Core、Extension 还是 Infrastructure？** 都不是 —— 本事项是 GOV（判据表 ＋ 生成物），**零运行时改动**。

⑥ **什么证据能够证明它完成？** `_gen_ai_toolmap.py --check` ⇒ **exit 0**（「缺中文名」那条消失）；
`_read_coverage.py --check` ⇒ ✅（读动作 70 / 不做 8 / 没交代 0）；
`_write_coverage.py --check` ⇒ ✅ exit 0。
