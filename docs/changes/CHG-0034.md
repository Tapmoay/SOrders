## ① 六问

① 我要解决什么问题？
报表中心现在的第一屏是**11 张彩色图标卡**（`ReportHome.kt` 的 `EntryCardGrid`），
用户看到的是一堆并列入口，答不出「这一段整体怎么样、钱在哪、接下来该看哪一张」；
他要的是**先给结论、再逐层往下**：第一屏按会计五个标准（利润表 / 资产负债表 / 现金流量表 /
运营分析表 / 关键指标表）**合并成一张卡**、每行像按钮，点进去**越点越细**，一路到订单。

② 当前用户 / 业务流程是什么？
派单员打开「报表中心」→ 看到 2 列彩色图标卡 → 估摸着点一个（营业纵览？经营利润？）→
进 `ReportCenterScreen` 的某个页签，页内自己一颗时间药丸。
「这一段赚没赚钱」这件事被拆在 3~4 个页签里，用户得自己记住哪几个数相减。

③ 哪个现有事实或能力会发生变化？
- 报表中心的**第一屏形态**：11 张图标卡 → 「经营状态一句话 + 五张表一张卡 + 要盯的事 + 走势 + 详细报表入口」。
- 报表中心的**导航形态**：扁平页签 → **节点栈（面包屑 + 返回上一层）**。
- 报表中心的**时间档位清单**：`DatePresets.ROW`（全部/今天/昨天/前天/这周/近 7 天/上周/本月/上月/近一年）
  → 报表中心这一处用**八档报表档**（今天/本周/上周/本月/上月/本季/本年/全部）+ 自选起止。
  既有档位与它们的区间**一个字节不改**（新增的两档只追加、`ROW` 不动，别的页面看不见变化）。

④ 哪些东西明确不能变化？
见 ② `Must Not Change`：后端零改动、老 11 页零改动、钱的口径零改动、权限零改动、
`DatePresets` 既有档位语义零改动。

⑤ 这个变化属于 Core、Extension 还是 Infrastructure？
**Presentation（L0）**：只画屏与导航；数都来自既有接口字段，页面自己不做金额加减。

⑥ 什么证据能够证明它完成？
模拟器 5554 上：① 首屏能看到五张表在一张卡里、每行有图标+一句话+大数+箭头；
② 点「利润表」能进到明细、再往下能到单据/订单；③ 时间药丸一个控件、点开是八档 + 自选；
④ 首屏每个数与既有页签（营业纵览 / 经营利润 / 车辆成本 / 客户欠款）**逐分对得上**；
⑤ 左侧抽屉里原来 11 个入口一个不少、点进去还是老页面。

## ⑥ CHG 专章

### Before

派单员点「报表中心」→ `ReportHomeScreen`：2 列彩色图标卡、11 格（营业纵览 / 商品经营 / 司机绩效 /
客户经营 / 资金收支 / 异常与审计 / 经营利润 / 车辆成本 / 成本覆盖 / 税账 / 客户欠款）。
要回答「这一段赚没赚钱」得自己点进「经营利润」，想知道"钱在谁手里"再点「客户欠款」，
两张屏之间没有路。

### After

> 这一版是照着**样板**做的：版式、口径与下钻链路都以 [报表中心样板存档（非生产代码）](../report-center-prototype/README.md)
> 为准（那里面有手机版测试网页、纯静态样板与两路只读接口盘点）；⛔ 不要再各写一套。

第一屏 = **一段话的结论 + 五张表一张卡**：

- 顶部：一颗时间药丸（📅 + 当前档 + ▾），点开八档 + 自选起止；
- 「经营总览」卡：五个标准各一行（图标 + 表名 + 一句白话 + 大数 + ›），整行可点；
- 「要盯的事」卡：该付司机的钱 / 超信用额度的客户 / 欠得最多的三个人 / 异常单；
- 「走势」卡：这一段的营业额按日（跨度大则按周）画柱；
- 「详细报表」卡：原来那 11 个入口（图标在文字上方），点进去还是老页面；
- 左侧抽屉：同样的 11 个入口 + 报表首页，滑出来就能换。

点「利润表」这一行 → 进「利润表」节点（营业收入 / − 商品成本 / ＝ 商品毛利 / − 司机运费 /
− 期间费用 / − 折旧 / ＝ 营业利润），每一行再往下：商品成本→成本覆盖、司机运费→司机绩效、
期间费用→费用明细、折旧→车辆成本、营业收入→商品经营/客户经营。
面包屑（五张表 › 利润表）常显，返回上一层就退一级。

- 钱的口径与所有金额字段
