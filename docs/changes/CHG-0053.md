## ④ Behavior Contract

- **Input**：这一单的 `order.addressLat` 与 `order.addressLng` 是不是**都**非空字符串（`hasCoords`）；
  点的那一下是**收货信息卡里地址那一行**（不是司机那块）。
- **Output**：那一行可不可点；行尾画不画「看地图」；点开后画不画那张只读地图（以及地图上的 marker 落在哪）。
- **Success**：两个坐标都在 → 整行可点 → 全屏只读地图：顶栏是这一单的收货地址（空则写「位置」），
  相机 16f 落到这一单坐标，marker 就在那一点；右上角能在「标准 / 卫星」之间切；点「关闭」→ 开关复位、marker 摘掉、地图 `onPause`。
- **Failure**：只有半个坐标（一个空一个非空）与"两个都空"**一个待遇**：不可点、不画「看地图」；
  就算开关被别处置起来，渲染块里的解析兜底（`placeLat != null && placeLng != null`）也不开 —— 不会出现一张没有点的空地图。
- **Boundary Cases**：
  · 地址**很长** ⇒ 顶栏 `maxLines = 2` ＋ `overflow = TextOverflow.Ellipsis`（长地址不许把顶栏撑爆）；
  · 地址**是空的**但有坐标 ⇒ 顶栏显示「位置」，地图照旧落到那一点；
  · **没装高德** ⇒ 与本弹层无关：它压根不碰高德（判据第 ③ 组钉着"全仓没有 viewMap、也没有 marker 网页"）；
  · 司机在下面那块点「高德导航」⇒ 仍走原来的 route 深链、仍可能跳出去（那是"怎么去"）；
  · 坐标是**脏数据**（越界 / 解析不出）⇒ `moveCamera` 与 `addMarker` 都在 `try/catch` 里：地图照旧能开、顶栏照旧显示，只是那一点落不准。
- **Side Effects**：只有视图副效果三条 —— 打开时 `mapView.onResume()` ＋ `moveCamera` ＋ `addMarker`；关闭时 `remove` marker ＋ `onPause()`。
  没有请求、没有写库、没有埋点、没有通知、没有权限申请。
- **Authorization**：无变化。谁能打开这张订单详情由既有权限守，本事项没碰。
- **Compatibility**：后端接口与出参**逐字未变**；改的只有本 App 这一屏 ＋ 一个新建文件。
