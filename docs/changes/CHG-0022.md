# CHG-0022 · 司机计费规则的新建 / 编辑从 AlertDialog 搬成单独一整页（十个字段改走共用行，错误落常驻底栏）

> 派单员「工作台 → 司机计费规则」这一页（`ui/dispatcher/DriverBillingRulesScreen.kt`）的新建 / 编辑表单，
> 原本整个塞在一个 `AlertDialog` 里：十段字段（「按分类计价」模式下还有每类两行）挤在弹窗里，
> 弹窗里还能再开一个占 90% 屏高的价目选择层 —— 正是设计规范 `docs/PROJECT_MAP/06_DESIGN_SYSTEM.md:762-763`
> 点名的那两条坑：「**表单带选择器时用单独一页**，不要塞进 `AlertDialog`：全屏选品层套在弹窗里就是
> 两层 modal 窗口叠着，而且字段一多弹窗会顶到屏幕边」（同处明说这条不限于记账页）。
> 本批把它搬成**同屏整页表单**：顶栏随表单切换（新建计费规则 / 编辑计费规则）、中间一整列滚动体、
> 底部常驻保存栏 —— 错误行画在常驻底栏里（画在滚动体末尾等于滚到底才看得见）。
> 十个字段一律走共用行 `FormInputRow` / `FormPickRow` / `FormTextAreaRow`，五个 `FormGroup` 白卡分组；
> 四个「少量互斥选项」保留 `SegmentedPicker`（包进 `PickerBlock`）。**后端、DTO、仓库层、权限、审计一行不改**。

## ④ Behavior Contract

```text
Input          点右上角「新建」，或某张规则卡右上的铅笔（编辑）。
Output         一页盖住整屏的表单：顶栏「新建计费规则 / 编辑计费规则」+ 返回箭头；

               底部常驻保存栏：错误行（有错才画）+ 满宽「保存」按钮。

Failure        校验不过 → 不提交，错误那句显示在**底栏**里（表单不关、字段不清）；
               后端报错 → 同样把后端那句话显示在底栏里，表单不关（用户改完接着点保存）。
Boundary Cases ① 「按分类计价」模式下每类两行（共 N 类）时整列能滚到底、底栏始终看得见；
               ② 键盘弹起时当前那一格不被顶出屏幕（整列可滚 + `adjustResize`）；
               ③ 价目层从表单里打开时，系统返回键先关价目层、再关表单；
               ④ 提成基数选「不抽成」时提成比例那一格灰掉（`enabled = false`）但仍在。
Side Effects   无（表单打开 / 关闭只是内存态；不写任何持久化东西）。
Authorization  沿用既有权能（这一页本来就只有派单员进得来），本事项不新增权限点。
Compatibility  **Compatible**：不改接口、不改 DTO、不改路由，形态变化对后端零影响。
```
