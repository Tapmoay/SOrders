`BorderStroke` + 图标），"按人搜索"那一档的搜索框也不是全 App 唯一那份 `SearchField` ——
同一件事在这一页有第二份答案，用户在别的页面学到的形状（语义色胶囊、放大镜 + ✕）到这里就换了样子。

② 用户进「地址与联系人」页 → 点顶部三档（路线 / 联系人 / 地址）切换列表 → 在搜索框里敲关键词过滤本地列表。
行为本身是对的，问题只在**形状与实现**：导航形态与组件速查（`06_DESIGN_SYSTEM.md` §3）不一致，
搜索框少了锚点图标与一键清空（手机号敲错一位要退格 11 次）。

③ 这一页的顶部导航由"私有实现"**变成共用件** `SegmentedStatusTabs`（导航形态随之统一：
无图标、语义色、选段淡色底）；联系人档的搜索框由 `SoTextField` + 「清除」文字按钮**变成**
`SearchField`（放大镜 + ✕ 一键清空 + 提示语同源 `core/UserSearch.HINT`）。

④ 不能变：三档的**语义色**（路线 ShipperTeal / 联系人 MgrGreen / 地址 MoneyOrange，第 3 批才谈色板归一）、
三档的切换语义（切档**清空关键词**）、线路 / 地点两档的占位语文案、搜索的过滤口径
（联系人走 `core/UserSearch.matches`）、抽屉与卡片的所有交互、后端与 DTO 一个字都不动。

⑤ **PRESENTATION**（纯呈现层）。

⑥ 判据 `_tools/qa/_check_address_tabs.py` 全绿 + 反向验证 `_reverse_verify_address_tabs.py` 每条注入都报红 +

## ⑥ CHG 专章

### Before

用户在「地址与联系人」页看到的顶部导航是一排**带图标**的描边胶囊（路线 / 联系人 / 地址），
每一格是私有 `AddressTabBar` 里的 `Surface` + `BorderStroke` + `Icon`；搜索框三档共用一个
`SoTextField`，只有"清除"两个字按钮，没有放大镜、没有 ✕。

### After

顶部导航变成全 App 唯一那份 `SegmentedStatusTabs`（**无图标**、语义色、选段淡色底、
放不下时整条横向滑动）；联系人那一档的搜索框变成 `SearchField`（放大镜 + ✕ 一键清空 +
提示语 `搜姓名 / 手机号（后 4 位也行）`），线路 / 地点两档保留 `SoTextField` 与原来的占位语，
清空同样是 ✕。

### Must Preserve

```text
- 历史订单 / 历史金额 / 已冻结的 Pricing Fact：不适用（本事项不碰订单与账本）
- 历史 Provenance / Audit / Ledger：不适用（不写审计）
- 权限：不适用（页面权限点没动）
- API compatibility：不适用（没有接口改动）
- 本事项特有的：三档语义色与顺序、切档清空关键词、联系人过滤走 core/UserSearch、
  线路/地点占位语（0 -> "搜线路：收货人 / 电话 / 地址" 是 _check_ai_guardrails.py:4074 的锚点，
  也是 _check_input_rules.py:101 的豁免键）
```

**L0** —— 只换了两份共用件的用法，没有字段 / 端点 / 迁移 / 权限 / 审计 / 并发 / 资金。
