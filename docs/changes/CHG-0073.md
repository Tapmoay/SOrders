## ⑥ CHG 专章

### Before

工作台上并排两格：「采购单」（绿）与「库存管理」（蓝青）。进货走采购单那条路是对的（同一事务写库存 ＋ 成本价 ＋ 供应商应付），但**库存页那条手工入库照旧摆在那里**：同一批货要是从库存页录，库存数字动了、**供应商不记、应付单不生成**（`inventory.py:65 create_movement`，`source="MANUAL"`）；用户看不到「这批货是哪张单进的」——流水行上只有一句 `note`（`purchase_service.py:175-176 f"采购单 #{order.id}"`）是死文本，点不动；想核这张单得自己回工作台再点「采购单」那一格去列表里找。

### After

工作台只剩**一格「库存管理」**（采购单从它进）。进库存管理页 → 顶栏「采购单」→ 原有那页采购单（列表 / 回收站 / 新增 / 改单 / 撤单 / 恢复，行为一个字没改）；顶栏「流水」→ 出入库流水里，属于某张采购单的行上多一颗可点的「采购单 #N」，**一点就进那张单**（口径 ④：「一行能点进它属于哪张单」）。手工出入库照旧在库存页（用户口径 ③：保留、老接口与历史流水一个字节不改）—— 只是它在新界面上明确是「库存调整」，而「一次进货」这件事以财务单的形式走采购单。
