**① 要解决什么**：用户 2026-10-22（语音，转述要点）四件事：
1. 「我们的订单[详情]……也是可以看到它时间信息的」——**下单页选了之后，别处看不到**；
2. 「重点是**提前一天**……像个**胶囊**……四周倒角……变深一点」——第二轮又校正了范围：
   「真正需要搞的信息就是 **3 个字：提前一天**……**其他的没必要搞**」⇒ 只有这三个字进胶囊；
   措辞也纠正过：是「提前一天**下单**」，不是"下达"；
3. 「**司机**可以知道这个订单大概是多少天……**派单员**也能知道，就能**提前做好规划**」——
   要的是"还剩几天"，不是"几号"；
4. 「如果他没选择的话，订单里**就有一条信息**说他没有选择送达日期」——**没选也要写出来**，
   ⛔ 不许整行消失（第二轮明确否掉了隐藏）；
5. 看完截图又纠正三条：①「这个**默认是空的**是不填的，**不是默认就填明天**」⇒ 下单页那一格
   **空着起步**、空着不许提交；②「**不保证准时**……也同样用我们的胶囊背景色，用**红色的深色胶囊**
   给框起来，这样子美观一点」⇒ 那一条做成红胶囊；③「那你也给那个**绿色的推荐**搞一个**绿色深绿色的底**啊」
   ⇒「推荐」也做成深绿胶囊（红＝要当心，绿＝按这个来，⛔ 两件事不共用一个颜色）；
6. 「把这个**提示**用**黄橙色**的警示底色……具体的就不用搞了，简单搞一下底色就可以，用黄橙色是为了与
   下面那个**红色做个区分**」⇒ 抽屉顶上那句解释句加**琥珀底**（0xFFFFF7DE 底 + 0xFF8F6C00 字，
   就是本页那条一次性提示的同一套配色），⛔ 不套 Surface（只挂 Hint 的 modifier，关掉提示时连同底色一起消失）。

**② 当前流程是什么**：FEAT-0028 只做了下单页那一格；订单卡片（三端共用）与订单详情都**没有**这一格
（当时的 Known Limitation ①：那两个文件正被 CHG-0124 / CHG-0125 改着，不敢同时动）。

**③ 哪个事实会变**：三处**显示**（下单页红条的排版、订单卡片多一行、订单详情多一行）；
数据一个字节不动 —— 用的还是 FEAT-0028 的 `orders.delivery_date`。

**④ 明确不能变**：
- ⛔ 后端：零改动（不新增字段、不加接口、不改迁移）；
- ⛔ 钱 / 状态机 / 权限 / 账本 / 通知；
- ⛔ 卡片上已有的三行人（收货人 / 下单人 / 货主）与商品胶囊、状态徽章（CHG-0124 正在调它们的深浅）；

## ⑥ CHG 专章

### Before

- 下单页红条：一整段红字（「订单必须提前一天下达；当天下的单，不一定能准时送达。」），
  六个字和后面的例外一样重，**扫一眼看不出哪句是规矩**。
- 订单卡片：**没有**送达日期这一行 —— 司机只知道自己有这一单，不知道"约的是明天还是后天"。
- 订单详情：**没有**送达日期这一行 —— 三方都要进这一页，却只有下单的人记得那天是哪天。

### After

- 下单页红条：**只有「提前一天」三个字**是深红胶囊（白字、四周倒角）；
  同一行其余是红字（「订单必须…下单」），下一行仍是红字「当天下的单，不一定能准时送达。」
- 日期那一格：**空着起步**显示「请选择」；抽屉里「今天」那条的「不保证准时」是**深红胶囊**、
  「明天」那条的「推荐」是**深绿胶囊**（⛔ 都不预选）；顶上那句解释句是**黄橙底色**；
  空着点提交 ⇒ 「请先选送达日期（订单要提前一天下达）」。
- 订单卡片：地址下面多一行 **「送达 10-23 · 还有 1 天」**（日历图标 + 小字；三端共用一张卡，
  货主 / 派单员 / 司机同时生效）。
- 订单详情：收货信息卡里、下单人下面多一行 **「送达日期　10-23 · 还有 1 天」**。
- 没有选过送达日的单（存量 / AI / 老客户端）：两处都写 **「未选择送达日期」**（⛔ 不隐藏）。
- 已送达 / 已撤销 / 已退货：只印日期「10-23」，**不再倒计时**。

### Must Preserve

```text
- 后端一个字节不动（字段 / 接口 / 迁移 / 审计）
- 卡片三行人（收货人 / 下单人 / 货主）的图标与深浅（CHG-0124 在途）
- 详情页可改行的细竖杠与铅笔图标（CHG-0125 在途）
- 没选过的单要明说「未选择送达日期」；终态单不倒计时
```

### Blast Radius（L0～L3）

**L1**（局部行为：三个显示点 + 一个纯函数；数据与接口零改动）。
