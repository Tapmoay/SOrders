### Before


- 名字列只剩 `288 − 58 − 10 − 48×4 = 28dp` ≈ **2 个中文字**（360dp 屏；412dp 屏约 5 个字），而分类名上限是 8 个字 ⇒ 必然显示不全；

### After

三档同形（`ui/dispatcher/ContactCategoriesScreen.kt` / `RouteCategoriesScreen.kt` / `PlaceCategoriesScreen.kt`，整文件重写）：

  → ⋮ `Icons.Default.MoreVert`（菜单：改名 / 删除，删除用命名 token `Color(MessageRed)`）；
  固定件 `58 + 10 + 48 + 48 = 164dp` ⇒ 名字列 `360 − 72 − 164 = 124dp` ≈ **8 个中文字**，正好装下 8 字上限；
- **列表**：`Column(Modifier.fillMaxWidth().weight(1f, fill = false).heightIn(max = 460.dp).verticalScroll(rememberScrollState()).padding(horizontal = 20.dp, vertical = 4.dp))`

- **拖动**：`onDragStart` 记 `draggingId` + 抹零偏移 + 一记 `HapticFeedbackType.LongPress`；`onDrag` 累加偏移并用
  `dragSteps(dragOffset, rowHeightPx)` 换算格数 → `vm.moveBy(c.id, steps)` → `dragOffset -= steps * rowHeightPx`；松手清状态；
- **VM**（三个同形）：新增 `moveBy(id, steps)`；`moveTo` 在 `submit(next)` 前先 `rows = next`；新增 `private var submitSeq = 0`，

- **返回**（`ui/shipper/AddressScreen.kt`）：`:152-159 leaveCategoryPanel`（关面板 + 按 tab 重读名册）、`:161-170 backOneLevel`
