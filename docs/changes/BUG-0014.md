     换成 `vm.ordersTab`（`vm.tab` 表达的是"用户想看哪一栏"，`vm.ordersTab` 表达的是

## ⑥ CHG 专章

### Before

司机在「进行中」看着一列红字大号的件数，点「已完成」：这一瞬间 `tab` 已经是 1，
而 `orders` 还是「进行中」那批 —— 卡片按 `highlight = vm.tab == 0` 算成 `false`，
于是**那批进行中的单**被画成紫色中号（"已完成"的样子）；等网络回来 `orders` 整体替换，
屏幕上才换成真正的已完成单。反过来从「已完成」切回「进行中」是同一个毛病的镜像。

### After

点「已完成」：`ordersTab` 仍是 0（屏幕上确实还是进行中那批），渲染门第一档判出
`ordersTab != tab` → 画 LoadingBox；取数回来后 `orders` 与 `ordersTab` **同时**变成 1，
才画出已完成的单 —— 颜色、字号与栏目自始至终一致，中途不再出现"错样式的对数据"。

### Must Preserve

```text
- 历史订单 / 历史金额 / 已冻结的 Pricing Fact
- 历史 Provenance / Audit / Ledger
- 权限
- API compatibility
- 自动退档（首次进「已完成」挑一个真有单的档位）与 windowSettled 闸门
- 司机端一律不画金额
```
