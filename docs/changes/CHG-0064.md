```text
Input：调用点传进来的 title / text / confirmButton / dismissButton / icon / tone。
       `tone` 缺省 = DialogTone.INFO（老调用点一个都不用改）。

Compatibility：Compatible —— 形参全是默认值，老调用点零改动；本事项内部把 62 处调用点一次性
```

## ⑥ CHG 专章

### Before

用户在真机上看到的：货主「我的订单 → 申请退货 / 撤回这张退货申请？」、派单员「退货 / 办理退货 /
驳回退货申请」这 4 处（以及全库另外 58 处）弹窗，全部是 M3 默认的**一层灰蓝底**（
`surfaceContainerHigh`，CHG-0063 之后是暖白家族里最深的那层 `#E1DDD5`）＋ 6dp tonal elevation，
没有图标；「删除 / 作废 / 撤回 / 解绑」与「改个默认售价」长得一模一样。用户的原话是
「那个弹窗太难看了，不符合我们的设计基调」。

### After

同一个动作：还是一张浮在中间的弹窗，但底是**白卡**（`colorScheme.surface` ＋ `tonalElevation = 0.dp`，
不再是那层灰），顶部多一个 28dp 的**语义色图标** —— 危险动作是红色 `Icons.Filled.Dangerous`
（返回/删除的三角标），提醒是橙色 `Icons.Filled.WarningAmber`，其余是提示蓝 `Icons.Filled.Info`；
图标形状与颜色**双通道**区分，色盲用户也读得到。危险动作统一走 `DangerConfirmDialog`（红色确认钮
＋ DANGER 档）；把这次修改回滚，用户看到的就是 Before 那一段。
