### R4-BOUNDARY-JUSTIFICATION：为什么边界解决不了这件事

这条缺陷的形状是**两个集合的差**：设置页渲染的是"这个角色能用的工具"（`toolsFor(role)`），

两个集合各自都对，**差出来那一项谁都不报错**：类型系统看不见集合元素，编译看不见 `linkedSetOf` 里少了谁，

## ⑥ CHG 专章

### 病灶：开关能点开、名字也存了，但**它不在"默认集"里**

`resolveEnabledTools` 的最后一句是：

```kotlin
val seen = seenAtSave ?: DEFAULT_ENABLED_TOOLS
val brandNew = DEFAULT_ENABLED_TOOLS - seen
return (saved + brandNew).intersect(DEFAULT_ENABLED_TOOLS)
```

那句 `intersect` 是**刻意的**：它把"已经不存在 / 不该生效"的名字挡在外面。代价是 —— 只要新工具**漏进**
`DEFAULT_ENABLED_TOOLS`，它就会在**这一句**上被静默筛掉：设置页点开、prefs 里存着、`AiTools.specs` 里没有、
模型说"我没有这个工具"。CHG-0096 的 `run_workflow` 就是这么漏的（同一形状在本仓**已经发生过一次**：
`remember` 当年也漏过，见 `docs/AI_ASSISTANT_PLAN_V3.md` 里那一段复盘）。

真机上的三段证据（2026-10-09 23:3x CST，`emulator-5554`）：

1. 设置页 →「AI 能用的能力」抬头写着 `查询 7/8 · 可读列表 39/39 · 改数据 2/2`，其中「跑工作流」那条开关
   （`[890,1320][1027,1446]`）是 `checked=false`；
2. 点开它 ⇒ `checked=true`，再 `cat shared_prefs/sorders_ai_prefs_u1.xml`：
   `enabled_tools` = `…read_data,run_workflow,export_sheet,…`（**存进去了**），
   `tools_seen` = `…read_data,export_sheet,…`（**没有它** —— 它是后加的，这是正常的）；
3. 退出这一页再进来 ⇒ 那条开关**又是 `checked=false`**、抬头**还是 7/8**；同一时间让模型跑
   `ledger.reconcile`，它回：「这个我查不了 —— 对账工作流（ledger.reconcile）在我这边没有启用，
   我跑不了它，也不会替它编一份结果出来。」（31.4k tokens，工具痕迹里没有一次 `run_workflow`）。

### 这次怎么做的

1. **默认集补上那一项**：`DEFAULT_ENABLED_TOOLS` 里 `READ_DATA` 之后加 `AiTools.RUN_WORKFLOW`，
   并在注释里写清"它为什么是只读的"（它只调读目录里的接口；要改数据只是把"该发哪张卡"交回去）。
2. **把这条失效形状写进源码注释**：常量自己的 KDoc 里点明"漏进这个集合 = 末尾那句 intersect 静默筛掉"，
   并把 `run_workflow` 这次被漏掉的经过记在里面（BUG-0022）。
3. **判据与单测各钉一遍**：判据去读那个 `linkedSetOf(...)` 的字面量里有没有 `AiTools.RUN_WORKFLOW`，
   同时钉住"末尾那句 intersect 还在""注释里点明了来历""两处单测名"；
   单测这边补的是**行为**：`resolveEnabledTools(saved + run_workflow, seenAtSave)` 必须含 `run_workflow`
   （即"用户自己点开的开关不许被筛掉"），以及"没点过它的老用户升级后自动有"。

### 判据与反验（这一单的红线，坏一处就必须红）

- 判据 `_tools/qa/_check_ai_workflow.py` **第 14 节**：默认集里有 `AiTools.RUN_WORKFLOW`、
  `intersect(DEFAULT_ENABLED_TOOLS)` 还在、源码里 `BUG-0022` 那段来历还在、
  两处单测名在、`BUG-0022.md` 九节齐全且写的是这条开关、登记簿/工作声明/台账各有一行、反验脚本在。
- 反验 `_tools/qa/_reverse_verify_ai_workflow.py` **10 条注入**：删掉默认集那一行 / 换掉那句 intersect /
  删掉来历注释 / 两处单测改名 / 文书缺一节 / 删掉文书里那份 prefs 证据 / 登记簿与工作声明改成别的单号 /
  台账那条改成别的说法 —— 每条都必须让判据变红，跑完逐字节还原。
