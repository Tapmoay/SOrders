# CHG-0023 · 名册页的信息层级按设计规范重做一遍（抽屉半展开 240dp / 名称与电话各给语义色 + 图标 / 账户管理拿回自己的棕）

> 用户 2026-10-05 原话：「呃还有这些啊，你已经改过的所有这些他那个侧边栏样式太不好看了，而且你看全部展开的话，
> 他属于啊内容又比较短太空旷了我们可以搞一个半展开，然后里面的那些内容，你要理解什么样的信息要突出那我们就将
> 什么样的信息给啊显示出来。包括我们这有张卡片啊，他也比如说我们重要的有有些还有什么信息啊，就是名称和电话号码吧，
> 我们要有对应的语义色和图标。让信息明确，这是我们的设计规范啊，你并没有按照我们的设计规范进行设计啊呃你改的那些
> 全都看一下有没有按照设计规范进行设计，然后重新把它们搞好？核心要点就是让该重要的信息凸显出来并且保持美观」
>
> 这一批做两件事：**① 左栏分类抽屉半展开**（M3 默认 ≈ 屏宽−56dp = 84%，内容短的时候右边一片空、下面的列表也看不见），
> 四个分类抽屉统一挂到新常量 `ui/common/CategoryDrawer.kt::CategoryDrawerWidth = 240.dp`（屏宽的 67%，右边留 ≈120dp 看得见列表）；
> **② 名册卡上那两条重要事实各给语义色与图标** —— 名称那行变成「本页模块色的圈底图标 + 16sp 加粗」，
> 电话那行变成「`Icons.Default.Phone` + `PhoneGreen` + 15sp 前景色（⛔ 不再是灰字）」+ 整行长按复制，
> 两件事各在 `ui/common/RosterCard.kt` 里只有一份实现（`RosterNameRow` / `RosterPhoneRow`），四个名册页共用。
>
> 顺带把「你改的那些全都看一下有没有按照设计规范」这句落实成一次复核：
> 「管理分类」面板里四颗裸 `IconButton`（18dp 图标）改成规范 §4.2c 的圈底图标 `CardActionIcon`、
> 面板里两处写死的地址页湖蓝 `Color(ShipperTeal)` 改成宿主页模块色的形参、撤销条从 `surfaceContainerHigh` 换回纯白 `SectionCard`（§5.0）、
> 两个裸 FAB 换成带字的 `ExtendedFloatingActionButton`、账户管理页不再借地址页的湖蓝而是拿回工作台宫格上自己的棕（`AccountBrown = #8D6E63`，
> 新增主题 token；宫格那一行**故意保留裸字面量**，`_check_ledger_dashboard.py` 的 `BAND_EXEMPT` 按裸值扫）、
> 司机/货主/批发商三页各按自己的能力池取模块色（黄绿 / 深青 / 金）。
> **后端、DTO、仓库层、权限、审计、迁移一行不改**。
