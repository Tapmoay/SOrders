# CHG-0116 桌面图标与启动画面：底色改成**纯白**（原来带一点绿）

- **ID**：`CHG-0116`
- **类型**：CHG（既有资源改值）
- **状态**：已关闭
- **Owner**：DSH `session-bd8fe093-bbe1-4814-af6d-586e0980ff81`
- **Blast Radius**：**L0 展示层**（两处颜色值：图标底色矢量 + 颜色资源；启动画面引用同一个颜色资源）

---

## ① 六问

```text
① 解决什么问题？  用户看实物后要求：桌面图标与启动画面**不要带绿**，要纯白底。逐字：「那个桌面的图标……那个
                  图案颜色没关系，但是那个背景图啊，是白底啊，不要是有一点绿了，不要带一点绿，白底就可以了。
                  我启动的那个界面也是一样啊，背景不要带点绿。」
② 当前流程是什么？ 图标底色是 CHG-0108 定的「照抄登录页」浅绿 `#DBE8E1`（`drawable/ic_launcher_background.xml`
                  的 fillColor ＋ `values/colors.xml` 的两个颜色名）；API 31+ 的系统启动画面用 `@color/splash_background`，
                  API < 31 露的是主题 `windowBackground`（白）。
③ 哪个现有事实会变？只有这两个颜色值 —— 图标**图案本身**（货车矢量）一个字不动。
④ 哪些明确不能变？ ① 图案的颜色与形状；② `splash_background` 与图标底色**继续同值**（它们本来就是一对，判据也对账）；
                  ③ API < 31 的白底行为不变；④ 启动画面的图标仍是 `@mipmap/ic_launcher`。
⑤ 属于哪一层？    Presentation（L0，资源值）。
⑥ 什么证据能证明完成？两个文件里再没有 `#DBE8E1`；`_check_palette_uniformity`(66)/`_check_green_theme`(40)/
                  `_check_low_sat_palette`(109)/`_check_ai_accent_green`(40) 全绿；装包后看桌面图标与冷启动。
```

## ② Must Change / Must Not Change

```text
Must Change:      android/app/src/main/res/drawable/ic_launcher_background.xml 的 android:fillColor → #FFFFFF
                  android/app/src/main/res/values/colors.xml 的 ic_launcher_background / splash_background → #FFFFFF
Must Not Change:  图标图案（ic_launcher_foreground.xml / monochrome）与它的配色、splash 与图标底色同值的关系、
                  themes.xml / values-v31/themes.xml 的结构（它们只引 `@color/splash_background`）。
```

## ③ Boundary

纯资源（Presentation）：两个颜色值。

## ④ Behavior Contract

- 桌面图标：**白底 + 原来的货车图案**；
- 启动画面（API 31+）：**白底** + 同一个图标；API < 31：主题 `windowBackground`（本来就是白）；
- 与登录页那块浅绿**不再同值** —— 这是用户明确的口径（"不要带点绿"），不是漏改。

## ⑤ Data Contract

不涉及。

## ⑥ CHG 专章

### Before

图标底色与启动画面底色 = 登录页浅绿 `#DBE8E1`（CHG-0108 定的"跟登录页一个值"），用户看到实物后要求换白。

### After

两处都是 `#FFFFFF`；图案不动。

### Must Preserve

图案配色、图标与启动画面底色同源、API < 31 的白底。

### Blast Radius（L0～L3）

**L0**：只有"图标/启动画面看起来什么底色"这一件事。

## ⑦ 测试（四件事都要）

- **Compatibility / Operational Safety**：纯资源值，无数据与协议影响；老包升级后图标由系统重绘。
