## ⑥ CHG 专章

### Before

派单员（`emulator-5554`，13800000001）→ 工作台 →「订单管理」（缺省档就是「派单中」）→ 搜索框粘进一张**已派单**的单号 `SO202610095032003138` → 点「搜索」：

- 屏幕正中只有四个字：**「没有匹配的订单」**；
- App 发出去的是 `GET /api/v1/orders?status=PENDING_DISPATCH&q=SO202610095032003138` → 200 空（这是**对的**：这一档就是只看派单中）；
- 而屏幕上标题写着「全部订单」、右上角药丸写着「不限时间」，**没有任何一处**写着"这一页只看派单中" —— 用户看到的是"这单不见了 / 搜索坏了"。

（同一台机器上货主页「我的订单」有**一模一样**的一段 `if`，只是兜底句是「暂无订单」。）

### After

同一个动作 ⇒ 一句话说清是**哪一档**在挡路，并给出出路：

- 派单员搜过、当前档带状态筛选 ⇒ **「「派单中」里没搜到 —— 这一页只看「派单中」，点页签「全部」可以搜别的状态」**；
- 点页签「全部」再点「搜索」⇒ 这张单**立刻**出来（`TA测试地址-派单池件数校验` / 已派单 / ¥44.1 / 红富士×3 ＋ 香蕉×2）—— 证明接口与数据本来就是好的；
- 当前档带日期窗口时照旧指右上角那颗药丸（搜过的多给一条"点页签全部再搜"）；
- 两页共用**同一份**判断（`ui/common/OrderEmptyHint.kt`），⛔ 下次不会再出现"只修了一页"。
