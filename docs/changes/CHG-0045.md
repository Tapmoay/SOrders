## ② Must Change / Must Not Change

```text
Must Change:
- 点「拍照送达」必须**直接进相机**（不再开抽屉）；拍完回到订单页就能看见缩略图；
- 照片区必须长在订单页里：缩略图可点开大图（走全库唯一那一份预览，顺带得到缩放 / 存相册）、右上角 ⊗ 可删、
  同一颗按钮继续拍（文案跟随张数：「拍照送达」/「继续拍照（N 张）」）；
- 「收取现金（N 张）/ 挂账（N 张）/ 提交送达（N 张照片）」三颗按钮必须移到**页面最底部**（内部备注下面）；
- **只有至少一张照片时**才出现完成入口（原先只有抽屉里那颗按钮带这个门）；
- 送达备注（可选）必须是页面内字段，且写在**内部备注上面**；
- 内部备注必须是页面内字段 —— **不许弹窗**，写进去是**追加一条**（后端 append-only），已有内容只读展示；

- **挂车直结**那条路（`order.freightVisible` → `vm.completeDirect`，不带照片）不受照片门约束；
- `completeDelivery` 的第二道照片门（`capturedPhotos.isEmpty()` 直接报错回来）；
```

## ④ Behavior Contract

```text
Input          司机在订单详情页点「拍照送达」/「继续拍照（N 张）」/ 缩略图 / ⊗ /「添加备注」/ 完成三颗按钮
Output         直接进相机；照片落 cacheDir/photos 后回到订单页，页面最底部依次是：送达凭证（照片 + 送达备注）→ 内部备注 → 完成块
Success        至少一张照片 → 提交送达（或收取现金 / 挂账）→ 上传照片 + 订单转「已送达」→ onBack；内部备注写成功 → 清空输入框、页面重读
Failure        一张照片都没有时完成块**根本不出现**；即使绕过界面，VM 的第二道门也会以「请至少拍摄一张送达照片」挡回；上传失败走既有错误回执
Boundary Cases 挂车直结（order.freightVisible）不受照片门约束，仍走 completeDirect；内部备注输入框为空时「添加备注」禁用；⊗ 删到 0 张 → 完成块消失；点缩略图看的是本地 File（不给「保存到相册」按钮）
Side Effects   上传照片、订单状态流转、内部备注追加一条（全部是既有通路，没有新增副作用）
Authorization  不新增权限点；内部备注沿用既有 ORDER_INTERNAL_NOTE 与司机/派单员白名单，界面两道门一字未放松
Compatibility  Compatible —— 契约、端点、字段都没变（只换了页面形态与完成入口的出现条件）
```

## ⑥ CHG 专章

### Before

```text
点「拍照送达」→ ModalBottomSheet(DeliverySheet)：
    Text("送达凭证") / Text("送达照片 · 自动加水印")
    缩略图 Row（可点开看一眼、右上角可删） + 一颗「继续拍照」
    送达备注输入框 + 货物破损（第二份）

内部备注 → 动作区里一颗按钮 → AlertDialog（写完关掉）
```

- 拍一张照要「开抽屉 → 拍 → 回抽屉 → 再点继续拍照」，照片只在抽屉里看得见；
- 完成按钮藏在抽屉最底下，司机在页面上根本看不到「这一单还没交」；

- 货物破损在页面与抽屉里各有一份（改了一处还以为没改）。

### After

同一单，页面从上到下：

- **入口直连相机**：`onCaptureClick = { capture() }`（`OrderDetailScreen.kt:264`）—— 抽屉那一步没了；

  `ImagePreviewState.open(models, at)`，右上角 ⊗ 删这一张）→ `OutlinedTextField("送达备注（可选）")`；
- **内部备注区**（`:1468` 起）：一句「只有司机和派单员看得到。写进去是追加一条，已有的那条不会被改动。」+
  `OutlinedTextField("再写一条备注（与派单员可见）")` + 「添加备注」按钮（空着就禁用）；
- **完成块**（`:1500` 起，页面最底部）：`role == DRIVER && order.status in COMPLETABLE && !order.freightVisible && photos.isNotEmpty()`
  四条同时成立才出现；「收取现金（N 张）」/「挂账（N 张）」/「提交送达（N 张照片）」；
- **拍照按钮只有一颗**（动作区那颗，`:1363`），文案跟随张数 —— 不再有两颗按钮干同一件事。
