① v2 页面（首页 + 各下钻节点 + 抽屉）里塞了二十多条**整句解释**：公式（「毛利率 = 商品毛利 ÷ 营业额」）、为什么（「这一天没有单就是 0」）、
指路语（「点哪一行，就往那一层细看」）。用户的原话是「解释反而全是字……反而不好看」，要求**没必要的全部删掉**；
另外左下角抽屉里每一行的图标内边距是 0（`LineRow` 本身不带横向内边距），卡片也是贴着屏幕左右边画的（`LazyColumn` 的 `contentPadding` 只有上下），看着挤。
② 派单员 → 工作台 → 报表中心（v2 首页：经营总览 / 五张表 / 要盯的事 / 走势 / 详细报表 / 口径说明）→ 点一行进节点 → 逐层下钻 → 订单详情。
③ 屏幕上**少了**二十多条解释句、`NotesCard`（「这几句话怎么读」整张卡）、自动挑档那句长提示、抽屉里两句说明；
「赚没赚钱（这一段）」「这一段真进真出多少」这类带「（这一段）」的副标题改成不带时间废话的短词。
卡片左右各留 12dp、抽屉里的项左右各留 16dp（标题与项对齐到同一条 16dp 的线上）。
**数字、比率、时点/区间标记、下钻链路、权限、接口一个字都不改**。
④ 钱的口径（页面只取接口字段；唯二的「页面相加」例外仍写在行上）、时点账与区间账不许混加、异常单固定「近 30 天」、
权限 ORDER_DISPATCH、路由与老 11 页、后端零改动、`DatePresets` 既有档位语义。
⑤ PRESENTATION —— 只改展示层的文字与间距，不碰任何事实与规则。
⑥ 模拟器 5554 上改造前 / 改造后的同一屏截图对照；`python _tools/qa/_check_all.py` 全绿；编译通过；
