⇒ 要的是：**这三处跟着全 App 的主题绿**（CHG-0091 刚把主色从亮蓝换成了低饱和深绿 `#00A870`），允许**一档色差**（不是死板的一个色值）；改完**三台模拟器都装上**。
② 用户是**派单员 / 货主 / 司机**三端。当前：AI 聊天页除了「自己那侧的气泡」「发送键」等少数几处，其余「表示这是 AI」的单色元素（顶栏三颗图标、⊕、会话选中态、抽屉、侧栏、块引、代码块描边）**全部读同一个常量** `AiAccent`；而它在 `AiChatScreen.kt:132` 写的是 `Color(AiBlue)`，`AiBlue` 是 Google AI 蓝 `#4285F4`。⇒ 全 App 都绿了，只有这一页还是一片蓝，用户看着别扭。
③ **会变的**：AI 聊天页的单色强调色（`AiAccent`）与 AI 设置页强调了色（`accent`）的**色值**（Google 蓝 → 主题绿）；发送键「可发送」那一档的色值（跟着 `AiAccent` 走 → 换成**深一档的绿** `ThemeGreenDeep`）。
④ **不能变的**：这一页的**任何**文案、图标形状（`History` / `AddComment` / `Settings` / `Add` / `ArrowUpward` / `Stop`）、按钮尺寸（发送键 52dp、⊕ 的 `TapTarget` 48dp）、可点区域、`onClick` 与 `enabled` 语义（`sending` 时发送键变 `Stop` 且点它=中断）、发送键三态（发送中=报错红 / 不可发送=浅绿 / 可发送=绿）、**AI 三段品牌渐变**（`AiBrand.kt` 的蓝→紫→粉，用在工作台 AI 圆钮与聊天空状态星标徽章）、后端**一行不改**、权限与 API、暗色主题那一套。
⑤ **Presentation**（只动展示层：两个 `ui/ai/` 页面里的色值）。
⑥ 见 ⑦ / ⑧：`_tools/qa/_check_ai_accent_green.py` 全绿 ＋ `_tools/qa/_reverse_verify_ai_accent_green.py`（每条注入都让对应那条变红）＋ 既有 `_tools/ai/_check_ai_guardrails.py` 同步改口径后仍全绿 ＋ 单测全绿 ＋ 编译绿 ＋ 三台模拟器装机 + 真机截图。
