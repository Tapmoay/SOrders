① **两种"找不到 / 不好用"**：
**(a) 入口放错了地方** —— 「单位换算」（设「1 车 = 8 方」这类换算，四个页面共用）长在**工作台九宫格**里，
与「库存管理 / 账本管理 / 车辆管理」混在一起；它真正服务的是商品数量（售价按袋 / 库存按方），
用户画红框要求把它挪到**商品管理顶栏**（紧挨「排序」左边）。
**(b) 派单那一层又丑又难用** —— 居中 `AlertDialog` 里：① 两档页签（选中档 `primary.copy(alpha = 0.14f)`、

提成 %）」两个框占着版面，而用户已经决定以后在订单里订（本轮**只删界面**，见 ⑤）。

② **派单员的两条路**：待派单池点「派单」/「批量派单」，或订单详情页底部点点「派单」——
两条路共用同一个 `AssignDriverDialog`（BUG-0004 定的「一处实现两个入口」）。点开后：选司机

**单位换算**：派单员（和货主）在那一页维护「1 车 = 8 方」，订单、库存、报表四处按它换算数量。
