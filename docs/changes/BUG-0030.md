## ⑥ CHG 专章

### Before

派单员（或 AI）把一行 3 × 20 的账本行合计改成 288：后端拒绝，并回一句
「账本行的「合计」必须等于 数量 × 单价：这一行是 数量 3 × 单价 20.00 = 60.00，与你给的 合计 288.00 不一致。…」——
同一屏上其它金额都是去尾零的写法（`¥87` / `¥56.7`），只有这句是机器味的 `60.00 / 288.00`。

### After

同样的动作，同样的 400，文案变成
「…这一行是 数量 3 × 单价 20 = 60，与你给的 合计 288 不一致。要改合计，请同时把数量或单价改成乘积等于它的值（例如 数量 1、单价 288 —— 记一整笔金额就这么写）。」
