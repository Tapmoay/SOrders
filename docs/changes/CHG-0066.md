## ⑥ CHG 专章

### Before

用户在真机上看到的：「创建于 09-19 18:09」—— 没有年份。跨年的单、或者对着一张半年前的单，
屏幕上没有任何一年可看；而单号本身就带着 8 位日期。用户的原话是「信息要非常详细」。
流转记录那一块是「09-19 18:09」这种紧凑写法（用户明确说这一块**不需要**年份）。

### After

同一个动作：「创建于 2026-09-19 18:09」—— 年份出现了，且仍按设备本地时区算（后端存的是 UTC）；
退货申请那一块的申请时间与办理时间同款。流转记录那六步仍是「09-19 18:09」，一个字没动。
把本刀回滚，用户看到的就是 Before 那一段。

### Must Preserve

```text
- 流转记录那一块（六步文案、顺序、紧凑格式）一字不改
- formatDateTime 本体与其全部既有调用点（列表页、退货申请列表页、司机运费页…）
- 时区口径：后端 UTC → 设备本地（parseBackendInstant 唯一入口）
- 历史订单 / 历史时刻（库里一直是完整 ISO，一行不改）
- 后端 / 接口 / 字段 / 权限零改动
```

### Blast Radius（L0～L3）

**L1** —— 一个 util 多一档 ＋ 一个页面三处调用点 ＋ 一份定位表的一行。不碰数据、不碰权限、不碰状态机、
不碰后端；坏掉的方式「全都不报错」（pattern 里少个 yyyy 也能编译、也能跑，界面上却看不见年份），
所以本刀必须自带判据与反验。
