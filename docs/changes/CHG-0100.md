① **缺陷出处**：`docs/TEST_BUG_LEDGER.md` 的 **TB-01**（方向 B 财务测试 2026-10-09 12:06 在 `emulator-5554` 上真机复现，严重度**可见**）与 **TB-03**（同批，严重度**可疑**）。TB-01 原文一句话：「工作台 → 挂账单位：每张卡片只显示 名称 / 电话 / 账期 / 信用额度 ＋ 删除 / 编辑，整页看不到「已挂账 / 已收 / 余额 / 已用额度」」。TB-03 原文一句话：「车辆成本表只累计「现在挂在这台车上的那位司机」的按单应付，没有挂车的司机整块不计入；月窗口两处数字差 5952 元（83%）」。

② **用户实际在做什么**：
- 派单员打开「工作台 → 挂账单位」，是想知道**这个单位现在还欠我多少、还能不能再赊**。这一页过去只印「信用额度 ¥8000」——那是"允许欠多少"，不是"现在欠着多少"。要看真实余额，他只能绕去「报表中心 → 客户欠款」翻到这一家；卡片点上去也没反应（`UnitCard` 只接了 `onEdit` / `onDelete`）。
- 财务方向测试在核「车辆成本表」与「利润表」时，两处"费用"对不上：车辆成本表的「= 成本合计」只含**现在挂在这台车上的司机**的配送成本，没挂车的司机整块不在里面（9 月窗口差 5952 元 / 83%），而页面上**没有一处**写着这个限定 —— 拿这张表的合计去对利润表，会以为有人算错了钱。

③ **变化的是"看得见什么、怎么读"**：
- 挂账单位卡片上**多一行数**：`已挂账 ¥5566.3 · 还能赊 ¥2433.7` / `已挂账 ¥3444.1 · 额度 ¥1894.26（已超）` / `已挂账 ¥68.8 · 额度：不限额` / `到目前还没有欠款记录` / `没有欠款 · 预收 ¥X`。这句话由一个**纯函数**（`ui/dispatcher/ArrearsBalanceLine.kt`）算出、**逐字来自接口**（客户欠款表的 `credit_used` / `credit_available` / `limit` / `over_limit` / `prepaid`），**客户端不做任何减法**。
- 余额这一路**自己记自己的错**：取不到时列表顶上多一行「余额没取到：<原因> ＋ 重试」，整页名册照旧画（⛔ 不许把整页换成错误页）。
- 车辆成本页：「车辆成本合计」下面多一句小字 `配送成本只算挂在这台车上的司机；没挂车的司机在利润表的「司机运费」里，不进这一格。`；两处 `= 成本合计` 的**标签**改成 `= 成本合计（只含挂靠司机）`；后端口径说明（`_NOTES` 第 3 条）**补一句**同一件事，让导出表头（`backend/app/api/v1/reports.py:329` 与 `_NOTES` 同源）也带上。

- **迁移怎么做 / Rollback 怎么办**：**无迁移**。Rollback ＝ 反向提交：删 `ArrearsBalanceLine.kt` 与它的单测、`ArrearsUnitsViewModel` 撤掉 `balances`/`balanceError`/`balanceLoading`/`fetchBalances`/`retryBalances`、`ArrearsUnitsScreen` 撤掉那两处 UI、`ReportCenter.kt` 两处标签还原、`_NOTES` 撤掉追加句、两份判据与两份反验各撤一节
