## ⑥ CHG 专章

### Before

用户在**任何一页**看到的身份色是**亮蓝** `#006DFF`：底部 Tab 的「派单作业」「工作台」、登录页与工作台顶部那条、报表中心的折线图与大数字、订单状态档位里「全部」那一档、金额/数量以外的强调字……全仓共 **39 处硬编码** `Color(0xFF006DFF)`，散在 19 个 `.kt` 里。
订单卡里的商品行是**一行**：行首一个**紫底方块图标**（`Icons.Default.Inventory2`，`ProductPurple`），接着**紫字**品名，右边**紫字**数量「×1 件」；多个商品之间用 `DashedLine()` 画一条虚线分隔。
页面底是**暖白** `#F8F7F4`（R > B，2026-09 台账 L-19 / CHG-0063 定的）。

### After

**①** 身份色是**低饱和深绿** `#00A870`：`Color.kt` 里 `ThemeGreen = 0xFF00A870L` 是唯一真身，`NavBlue` 与 `InfoBlue` **都成了它的别名**（所以全仓 16 处调用点、包括底部那两个 Tab 和 5 个管理页，一个字都没改就跟着换了）。`Primary` / `PrimaryContainer`(`#D6F2E4`) / `OnPrimaryContainer`(`#0B4A32`) 换成绿家族 ⇒ 工作台顶部那条顺手变成**浅绿底 + 深绿字**。剩下 39 处硬编码全部收成 `Color(ThemeGreen)`，全仓再没有一处残留的 `0xFF006DFF`（唯一豁免是 `Color.kt` 里的 `SeedBlue`，那是**暗色主题**在用）。
**②** 订单卡里的商品变成**一块一个商品**：`Column(spacedBy(6.dp))` 里每个商品一块 —— 圆角 `shapes.medium` + 浅绿底 `ProductRowTint` + 左右 8dp / 上下 6dp 内边距；块内左边是**绿 tint 圆底图标**（13dp / 容器 22dp），中间是**近黑墨绿** `OnProductRowTint` 的 SemiBold 品名（Ellipsis），右边是**深绿块 `ThemeGreenDeep` + 白字**的数量。多商品就是多块，**不再画虚线**（`DashedLine()` 函数**已删** —— 没人调用的私有声明过不了 `_tools/qa/_check_dead_code.py`，它那两条结论搬进了 `OrderCard.kt` 的「行4」注释）。
**③** 页面底那四层（`BackgroundLight` / `SurfaceVariantLight` / `SurfaceContainer` / `SurfaceContainerHigh`）从暖白改成**中性近白**（`#FBFBFA` / `#F3F2EF` / `#EFEEEB` / `#E9E7E3`）—— 台账 L-19 / CHG-0063 立的「暖白 R > B」那一版就此改成「中性近白」，判据 `_check_warm_surface_palette.py` 同步从 `WARM` 改成 `NEAR_WHITE`（放宽成 `R >= B`，不是把这条规矩废掉）。
**④ 当天撤回的两件**（ref `m02715`）：上午还按 m01501 铺过「页面顶深绿 `#006A3A` → 到 1/3 处纯白」的渐变、并把 `AppTopBar` 顶栏改成浅绿 `PrimaryContainer`；用户看完说「那个背景的渐变，就去掉吧……那个也去掉啊，就是白色的默认色」⇒ **两处都退回原样**：`RoleHomeScreen` 那一层的 `TopGreenFade` 与 `Scaffold` 的透明容器**整段删掉**（连 `Brush` / `Color` 两个 import 一起清），`AppTopBar` 读回 `background`，死掉的起色 token `PageGradientGreen` 也从 `Color.kt` 删掉（不留没人用的 token，与 `OnThemeGreen` 同一口径）。判据第 4 节从此反过来钉「主界面不许再自造背景、那个 token 不许再出现」，第 5 节钉「顶栏读的是 `background`」。

### Blast Radius（L0～L3）

**L1 —— 局部行为**。不改数据、不改权限、不改接口，所以不是 L2/L3；但它**不是一个文件的纯展示改动**：同一屏上多处颜色一起变（底部 Tab + 顶栏 + 卡片 + 图标），而仓库里有一条机器判据要求**同屏两个模块色的 RGB 欧氏距离 ≥ 60**（`android/app/src/test/java/com/tapmoay/sorders/ui/nav/ModulesEntryTest.kt`），新主色必须与已有的绿（`MgrGreen #00B578` / `Success #00A56E`）都拉开（实测 `#00A870` 对它们分别是 **70** 与 **66**，都过线）。所以按 L1 处理：配判据 + 反验 + 真机取证。
