② **当前用户 / 业务流程是什么？** 见 ⑥ 的 Before。

   但按钮背后那套 state（权限 / 收集 / 兜底）**跟着搬到表单**，所以是 L1 而不是 L0。
⑥ **什么证据能证明完成？** 见 ⑧。

## ② Must Change / Must Not Change


## ④ Behavior Contract

```text
Input          点「我就在这里」
Output         ① 已授权 → 单次定位 → 回填收货地址（+ 坐标）
               ② 没授权 → 申请权限 → 同意后同上；拒绝 → 抽屉里那句中文提示（在表单里）
               ③ 拿到了但不可信（(0,0) 之类）→ **只提示、表单一个字不改**
               ④ 正在定位 → 按钮变「正在定位…」且不可再点
Failure        定位不可用 / 权限被拒 → 如实提示（仍然可以走地图选点）
Boundary Cases 连点两次 / 定位中关页面 / 权限只给粗略位置（两者都申请）
Side Effects   无（⛔ 不写库、不建地点）
Authorization  与页面其它动作一致（货主端与派单员端都能用）
Compatibility  Compatible：不改接口、不改数据；按钮换了个位置
```
