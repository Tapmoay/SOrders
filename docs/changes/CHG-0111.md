- **状态**：已关闭
- **Owner**：DSH `session-bd8fe093-bbe1-4814-af6d-586e0980ff81`
- **Blast Radius**：**L0 展示层**（只改 `AccountManageScreen.kt::labelColors` 的取色，不改任何数据与逻辑）

## ① 六问

```text
① 解决什么问题？  用户在真机上点出来：「你这个挂着司机他那个显示的是不是非常的不好啊，那个字迹颜色不匹配啊」。
② 当前流程是什么？ 账户管理页的角色标签由 AccountManageScreen.kt::labelColors 取色：三种司机**各写各的**，
                  其中挂车司机是 #FFDE9B 底 + #FF0F00 字（琥珀底 + 纯红字），大车司机是 #EFF6AE 底 + #817800 字，
                  小车司机又是另一套青；而红色在本仓库是**危险/异常**的专用色。
③ 哪个现有事实会变？只有那一个标签的**取色**；用户数据、角色判定、号码一律不变。
④ 哪些明确不能变？ ① 角色判定（u.role / u.vehicleType 的三种码 small/large/trailer）不变；
                  ② 其它角色的色（派单员蓝 / 货主青 / 批发商琥珀）不变；③ 不把红色用在正常角色上。
⑤ 属于哪一层？    Presentation（L0）。
⑥ 什么证据能证明完成？真机（USB 72e5048）装 0.2.10 后截「账户管理」页：三种司机同一个绿；
                  派单员/货主不变（截图 _tmp/real_accounts_after.png）。
```

## ③ Boundary（Core / Extension / Infrastructure / Presentation）

纯 Presentation：一个取色函数的 when 分支。零后端、零数据、零接口。

## ④ Behavior Contract

- 账户管理页每个账号卡右上角仍是一个「浅底 + 深字」的角色标签；
- **三种司机（小车/大车/挂车）现在是同一个绿**（同一个身份不该有三种颜色），车型由**文字**区分；
- 派单员=蓝、货主=青、批发商=琥珀（都照旧）；
- ⛔ 红色不再出现在任何**正常角色**的标签上。

## ⑤ Data Contract

不涉及（纯取色）。

## ⑥ CHG 专章

### Before

挂车司机 = 琥珀底 + **纯红字**；大车司机 = 淡黄底 + 橄榄字；小车司机 = 淡青底 + 深青字。
用户的原话是「字迹颜色不匹配」—— 红字在别的页面都表示「异常/危险」，这里却挂在一个正常角色上。

### After

三种司机统一 `#DCF2E6` 底 + `#0B5C3B` 字；其余角色不变。

### Must Preserve

角色判定不变（`vehicleType ∈ {small, large, trailer}`）；标签仍是「浅底+深字」的包章风格。

### Blast Radius（L0～L3）

**L0**：只有这一个页面的一张卡片上的一个标签。

## ⑩ 追加（2026-10-11 00:5x，用户第二条口径 —— 覆盖 §④/§⑥ 里「三种司机同一个绿」的写法）

用户逐字：「**挂车和大车司机都要做区别啊，不能用一样的颜色**。我是说，那个字和他的底部背景的那个颜色要**一致**啊。上一个就是不一致……大车司机还可以用原来的那个偏淡黄的嘛，挂着司机可以用这个颜色。」

⇒ 最终落地（**以这一条为准**）：

| 角色 | 底色 | 字色 | 说明 |
|---|---|---|---|
| 挂车司机 | `#DCF2E6` 浅绿 | `#0B5C3B` 深绿 | 同一色系 |
| 大车司机（含未写车型的老账号） | `#EFF6AE` 浅黄 | `#6B6400` 深黄 | 同一色系（用户点名「用原来那个偏淡黄的」） |
| 小车司机 | `#D7F9FD` 浅青 | `#00646A` 深青 | 同一色系 |
| 派单员 / 货主 / 批发商 | 蓝 / 青 / 琥珀 | 同系深色 | 不变 |

- ⛔ 不变的两条：① **红色只属于异常/危险**，不许当正常角色的字色；② 每一对都必须是**同色系浅底 + 深字**（用户的原话就是「字和他的底部背景的那个颜色要一致」）。
- 证据：真机 `72e5048` 装 0.2.11（`2026101007`）后「账户管理」页截图 —— 三种司机三色，且各自字色与底同系。
