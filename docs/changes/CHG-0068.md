## ⑤ Data Contract

- **新增/改动哪些字段**：**无**。`SupplierCreateRequest(name, contact_name, phone, address, remark)` 一个字段没加 —— 就地新建只是"少填几个"，没填的仍是空串。
- **Owner 是谁**：供应商档案的 Owner 仍是后端（`backend/app/api/v1/suppliers.py`；归属表见 `docs/R4_CORE_EXTENSION_MAP.md` §3/§4）。界面这一层不拥有它。
- **什么时候写 / 什么时候不写**：只有用户**真的点了**「建好并选中」才发一次请求；打开弹层、改一半关掉、只搜不建，都不写。
- **是否允许 NULL**：地址 / 备注留空 ⇒ 后端存**空串**（与在档案页建出来的一条逐字段相同），不是 `NULL`，也不是 `unknown`。
- **历史数据怎么办**：老档案一个字不动。就地新建出来的档案**看不出**是在哪儿建的 —— 也不需要有这个信息：同一张表、同一条审计、同一套字段。
  ⛔ 不新增"从哪儿建的"这类字段去反推历史（过去没有 provenance 就不许按现在的规则猜过去）。
- **迁移怎么做 / Rollback 怎么办**：**没有** schema 变更，不需要迁移。回滚 = 撤掉这几处界面入口（共用弹窗本身可以留着给档案页用）。
- **删除本功能后历史数据还能不能解释**：能。建出来的供应商与在档案页建的**结构上不可区分**，删掉入口不影响任何一条已存在的档案。

## ⑥ CHG 专章（FEAT / GOV 不适用时写「不适用：<理由>」）

### Before

建采购单 / 进项票时点「供应商」那一行，弹层只列名册、只能选。名册是空的时候，弹层上那句话是**支使**：
采购单弹层「还没有供应商档案，先去「供应商 / 厂商」建一个」（旁边只有一颗「重新加载」），进项票弹层「还没有供应商 —— 先去「供应商」里建一家。」。
用户要建的那家不在名册里时，唯一出路是**退出这一页** → 去档案页建 → 回来重新点开弹层重选。采购单保存时如果还没选，只得到一句「还没选供应商」，没有任何下一步。

### After

两处弹层底部都多一颗「**新建供应商**」：点开一张最小表单（**只问名称 ＋ 电话**，底部一行提示「地址、备注以后可以在「供应商 / 厂商」页补」），
点「建好并选中」⇒ **建完直接选中刚建的那家**、两个弹层一起关掉，人回到原来的表单上，供应商那一栏已经填好了（采购单上还会用提示条补一句「已建档案：<名字>」）。
弹层的空态句从"支使你去别处"改成**入口**：「还没有供应商 —— 现在就建一家」。
采购单保存时那句变成「**还没选供应商 —— 现在就建一家**」，并且提示条上**多一颗按钮**「现在就建一家」——点一下直接开选供应商弹层。
档案页那两处（新建 / 改资料）**形态与以前逐字一致**：仍然是全字段（名称 / 联系人 / 电话 / 地址 / 备注），只是那份弹窗现在住在 `ui/common/` 里、由两个页面共用。

### Must Preserve

```text
- 历史订单 / 历史金额 / 已冻结的 Pricing Fact
- 历史 Provenance / Audit / Ledger（建供应商仍记 SUPPLIER_UPSERT，一条不多一条不少）
- 权限（仍是派单员的 POST /suppliers）
- API compatibility（端点、DTO、状态码一字未改；老包行为不变）
- 供应商页那两处弹窗的全字段形态；选客户弹层；进项票既有错误行措辞
- OneShotSnackbar 既有调用点的行为（不传按钮 = 与以前逐字相同）
```

### Blast Radius（L0～L3）

**L1** —— 只动界面入口与一个共用零件的可选参数：不碰金额、库存、状态机、审计、后端与数据库；出错的后果是"按钮没有出现 / 没有选中"，最坏也只是回到"去档案页建"的老路。
