## ③ Boundary（Core / Extension / Infrastructure / Presentation）

**结论：Presentation —— 只动「同一串过程什么时候摆出来」，不动过程本身。**

- 为什么不是 Core：没有新的数据事实、没有新的权限判定 —— 那串步骤的**文字**一个字节没变（判据第 2 节逐条钉着 3dp 色条与 `if (expanded)` 的位置）。
- 为什么不是 Extension：不是「加一个能力」，是**换一种摆法**（同 CHG-0092 的判定口径）。
- 为什么不是 Infrastructure：不碰网络、存储、构建产物；折叠状态不进消息模型、不落库。
- 为什么复用「思考过程」的折叠形态而不是新造一个：用户口径就是「像思考过程一样」—— 同一页里两块过程必须是同一种交互（点一下开合），否则学两套。
- 为什么两处**故意**做得不一样（chevron 放**标题行右端**、状态用 `rememberSaveable`）：
  ① 这一块标题行左端已经有一条 3dp 色条，把 chevron 插在色条与文字之间会让标题比下面的步骤多缩进 22dp；放右端则标题与步骤行文字左对齐，步骤行（有会折行的长句，如「正在改数据（需你确认）（{"action":"address.crea…")」）也不丢宽度。
  ② `LazyColumn` 会把滚出屏幕的消息项销毁 —— 普通 `remember` 会让「展开了又自己收回去」；`stateKey = index` 让展开态跟着这条消息走（消息身份就是下标，见 ⑤）。

## ④ Behavior Contract

```
Input      ：步骤行列表 lines ＋ running（这条消息是不是还在生成）＋ stateKey（消息身份）
Output     ：折叠态 = 一行标题（色条 ＋ 文案 ＋ 右端 chevron）；展开态 = 标题行 ＋ 逐条步骤
Success    ：默认折叠（一进页面就是一串变一行）；点标题任意位置开合；跑完的标题写着「查看执行过程 · N 条」；
             还在跑的那条写着「执行过程 · 进行中」
Failure    ：一条步骤都没有 → 不画（调用点已判空），标题也不留空壳
Boundary   ：滚动出屏再回来 → 展开态保住（rememberSaveable + 消息下标）；
             展开 > 进行中 > 条数（三档优先级：展开时说的是「点下去会发生什么」）
Side Effect：无（纯界面状态；不写库、不发请求、不改全局状态）
Authorization：无（呈现层不看角色）
Compatibility：展开后每一行步骤与改前**逐行一致**；MessageRow 其它内容不变
```

## ⑤ Data Contract

不适用：本单不新增 / 不修改任何数据结构、接口字段、数据库列或本地存储键。折叠状态**不进** `UiMessage`（`ui/ai/AiChatViewModel.kt:67` 起，字段有 `role/text/toolTrace/reasoning/at/tokens/undoToken/undoLabel/attachments/attachmentBlock/exportRecipe…`）—— 它是 `rememberSaveable` 里的界面状态；消息身份就是列表下标（`AiChatScreen.kt:551` 的 `items(count = vm.messages.size, key = { it })`）。

## ⑥ CHG 专章

**Before**

- `ToolTraceStrip(lines: List<String>)` 恒展开：`Column` 里 `lines.forEach { Row { 色条 + Spacer(8.dp) + Text(line) } }`，**整块不可点**，也没有「几步」这个概念。真机一次提问常出 10+ 行 ⇒ 用户说的「步骤太多的话，使得整个界面太过冗余了」。

**After**

- 同一块折成一行标题（`traceHeaderLabel`：`查看执行过程 · 11 条` / 还在跑时 `执行过程 · 进行中`），点一下才逐条展开；展开态跟着消息下标走，滚出屏幕再回来还在。
- 「进行中」只属于**最后一条**（`vm.sending && i == vm.messages.lastIndex`）—— 这也是本单顺手修掉的一处语义错位：改前 `MessageRow` 收的就是全局 `vm.sending`。

**Must Preserve**

- 思考过程那一块、每一行步骤的文案与顺序、3dp 色条与 14sp 字号、MessageRow 的其它内容、后端与数据库。

**Blast Radius**：**L1 —— AI 助手聊天页的那条「执行过程」痕迹带**。影响面：助手气泡上方那一块的默认折叠状态与标题文案；不动后端、不动数据、不动权限、不动模型能力。
