## ④ Behavior Contract

```text
Input          手指在看大图的整屏上横向拖动（1 张时也可以拖，但没有"下一张"）；或点商品图那三个位置里的一张。
Output         1x 时：图跟着手指横移；松手位移过阈值（整宽的 18%）→ 翻到上一张 / 下一张（到头即停），不过阈值 → 回正。
               放大时：横向拖动＝平移（仍被 clampPan 夹在边界内）；已经贴到左右边界还继续往外拖 → 累成"待翻页"，
               松手过阈值才翻；翻页后缩放与位移都归位（remember(index)）。
               商品图：点图 → 打开唯一那份预览，只这一张（没有箭头 / 计数 / 翻页）；图是空的 → 那一下没有热区。
Success       滑一下就翻页（不用去找箭头）；到头就停住（第一张往右、最后一张往左都没有反应）；
               箭头同步：第一张不画左箭头、最后一张不画右箭头；商品图点开就是"放大看图"。
Failure       位移不够 → 不翻页、图回正（不产生"翻了一半"的中间态）；到头继续滑 → 停在原位（⛔ 不环绕）；
               空图 → 没有热区（不出现"点了没反应"）。
Boundary Cases 单张图（models.size == 1）：不画箭头 / 计数、拖动不翻页（只可能平移，1x 时归零）。
               放大到 5x 贴住右边界再往左拖 → 先平移，贴边之后继续拖才积累翻页位移。
               竖着拖（abs(dx) <= abs(dy)）：不算翻页（这是"看图"不是"翻页"的歧义场景，宁可不动）。
               连续快滑：每次翻页都重新起算位移（翻完归零），不会一次跳两张。
Side Effects   无（不改任何数据、不发任何请求）；翻页只改本地 index，弹层关掉即丢。
Authorization  不适用：预览是纯本地 UI，图本身的可达性由后端静态资源与既有权限决定（本次不碰）。
Compatibility  Compatible（纯客户端；后端 / API / 数据一个字不动）。
```

## ⑥ CHG 专章

### Before

看大图（订单详情的地点照片 / 司机送达照片、下单页与地址页的位置参考图）时，**翻页只能按屏幕左右那颗箭头**：手指横向划过去毫无反应（`ui/common/ImagePreview.kt` 里只有 `detectTapGestures` 与 `detectTransformGestures`，横向 `pan` 全给了"放大后拖动"，1× 时还被 `:163` 的 `if (next <= MIN_SCALE) Offset.Zero` 直接吞掉）。两个箭头是**环绕**的（`:219` `(index - 1 + models.size) % models.size`、`:225` `(index + 1) % models.size`）：第一张再按左会跳到**最后一张**，最后一张再按右会跳回**第一张** —— 人看到的是"我明明在最前面，怎么一下到末尾了"。底部提示句只有「双指缩放 / 双击放大」，**一个字没提翻页**（手势是藏起来的功能，不写一句没人知道）。商品图那边：商品管理列表卡的 88dp 图、选品行的 56dp 图**点不动**；勾选行 40dp 点图＝**勾选 / 取消**（不是看图）；商品编辑页那颗 168dp 点图＝**重新选图**。

### After

同一个动作：**手指横滑就翻页**（1× 时图跟着手指走，松手按位移定夺；到头就停住，不环绕）；放大之后横滑仍然是**平移**，只有已经贴到左右边界还继续拖才算"待翻页"—— 即"缩放"与"翻页"两个需求同时成立的唯一分法（⛔ 不会出现"放大后滑不动"）。箭头**同步**改成到头即停：第一张不画左箭头、最后一张不画右箭头（用户 m01517：「首章和末章的箭头就是俺藏起来吧……因为你首张的左边箭头怎么可能会有呢？」），底部提示句补上「左右滑动翻页」。商品图：**商品管理卡 88dp / 选品行 56dp / 勾选行 40dp 三处点图＝看这张图的大图**（只有放大看图，没有箭头 / 计数 / 左右翻页 —— 用户 m01486：「商品图不要加左右滑动 —— 商品图只有放大看图」），空图不给热区；**商品编辑页那颗 168dp 一个字不动**（m01532：「商品的编辑页面是重新选图的，它不是查看图片的」）。
