## ① 六问

① **我要解决什么问题？** `CHG-0114`（`faca4df3` 实现 ＋ `fb6c30b5` 台账回填）把 AI 输入框的提示语
从「派单员/货主两条常量 if-else」改成**按 `AiSuggestWho` 三档查表 ＋ 认不出角色时 fail-closed 兜底**
⇒ `_tools/ai/_check_ai_guardrails.py` 里那条红线「输入框提示语按角色给」**认不出新形状**。

② **现在是什么样 / 为什么现在不行？** 断言原来钉的是字面形状
`hint = if (ai.currentRole == AiRole.SHIPPER) HINT_SHIPPER else HINT_DISPATCHER`；
新形状是 `hint = suggestWho?.let { HINT_BY_WHO[it] } ?: HINT_FALLBACK`。
**红线的意图一字没变**（提示语必须按角色给、⛔ 不许举这个身份做不到的例子），
但形状变了、而且多出**第三类身份**（批发商 —— 他最该看的是"我的货主欠我多少"，
而不是普通货主最该看的"加一个常用地址"）。

③ **改成什么样？** 断言改成查表形态并**逐档点名**：
· `present` 改成 `hint = suggestWho?.let { HINT_BY_WHO[it] } ?: HINT_FALLBACK`（新形状）；
· 新增 `present`：三档提示语在一张表里（`private val HINT_BY_WHO = mapOf(`）、
  表里 `AiSuggestWho.DISPATCHER to` / `AiSuggestWho.SHIPPER to` / `AiSuggestWho.MEMBER to` 各一条；
· 两条 `absent` 从"按常量块找"改成**按各自那一行查**
  （`block_between(screen, "AiSuggestWho.SHIPPER to", "\n")` 与 `AiSuggestWho.MEMBER to`），
  仍然各自钉「不许举例库存 / 司机 / 导出」；
· 在断言上方补注释写明 `CHG-0114` 的来由（批发商是第三类身份）。

④ **哪些东西明确不能变化？** ⛔ 红线的**意图**不许放宽（按角色给 ＋ 不许举例做不到的事）；
⛔ 不删任何一条 `absent`（只把查找锚点换成新形状）；⛔ 不改 `ui/ai/AiChatScreen.kt` 的实现与文案；
⛔ 不把断言改成"只要有 hint 就算过"。

⑤ **属于 Core、Extension 还是 Infrastructure？** 都不是 —— GOV（判据锚点随动），零运行时改动。

⑥ **什么证据能够证明它完成？** 本会话复跑 `python -X utf8 _tools/ai/_check_ai_guardrails.py`
⇒ ✅ **全部 1351 项通过**（EXIT=0）。
