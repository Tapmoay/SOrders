## ⑥ CHG 专章

### Before

详情页点一张送达照片 / 位置参考图：

```text
Dialog(onDismissRequest = { previewUrl = null }) {
    AsyncImage(model = resolveStaticUrl(url), modifier = Modifier.fillMaxSize().clickable { previewUrl = null }, …)
}
```

- 只能"看一眼、再点一下关掉"：没有缩放、没有平移、没有保存、没有翻页（同组第二张看不到）；
- 拍得远时门牌号 / 货损细节看不清，用户只能拿另一台手机拍屏幕；
- 地址页与下单页用的是 `ImagePreviewDialog`（有翻页 + 计数 + 黑底），但也没有缩放与保存
  ⇒ 全库"同一件事"三处入口，能力还不一样。

### After

同一张照片，三个入口都是同一份 `ImagePreviewDialog`：

- **双指缩放** 1×–5×（`detectTransformGestures` + `graphicsLayer`，不重排布局）；放大后可拖动，
  边界 `clampPan` = `(n−1)/2 × 边长`，所以图不会被拖出屏幕再也拿不回来；
- **双击**在 1× 与 2.5× 之间切（不是"一直放到最大"）；换图 / 翻页时缩放与位移都归位（`remember(index)`）；
- **单击语义**：1× 时＝关闭（老行为一个字没变）；放大后＝先回到 1×，再点一次才关（`detectTapGestures` 取代 `.clickable`，
  否则拖动 / 捏合中途抬手会把预览关掉）；
- **保存到相册**（右上角 ⤓）：只对服务端路径的图出现；`resolveStaticUrl` 拼全地址 → 共享 `NetworkDns.okHttp` 取字节（IO 线程）
  → `saveImageToGallery` 落盘（也切 IO）→ 成功「已保存到相册：<文件名>」/ 失败「保存失败，请检查网络后重试」；
  `image/jpeg` + `Pictures/SOrders`，Q 以下写完喊一次媒体扫描（否则相册要等下次开机才看见）；
- 底部一行「双指缩放 / 双击放大」—— 手势是藏起来的，得有一句提示。

⚠️ 回执用 **Toast**（`Toast.makeText(...)`，`ImagePreview.kt:178/189-194`）：弹层是全屏黑底、盖在 Scaffold 之上，
Snackbar 会画在它**下面**看不见，而 Toast 浮在最上层 —— 成功「已保存到相册：<文件名>」、失败「保存失败，请检查网络后重试」、
这张图本来就没有可下载的地址时「这张图没有可下载的地址」。
