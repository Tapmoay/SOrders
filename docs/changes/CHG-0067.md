## ⑥ CHG 专章

### Before

用户在下单页点收货地址，弹出「选择收货地址」抽屉。左栏每一格**只有文字**（线路 / 我的地点 / 共享地点 / 自定义分组名 / 管理分组），选中的那一格是**白底**加左边一条湖蓝竖条。「管理分组」与它上面那些"换右栏内容"的格**紧挨着、没有任何分隔**，手指少一格的偏差就会从"选分类"变成"跳去管理分组那一页"。同一屏里，从「线路分类」那个抽屉看过去，那一列却是"图标 + 浅青色底 + 选中对勾 + 「管理分类」前面一条线"。

### After

同一个动作：左栏每一格**带图标**（线路=Route、我的地点=Home、共享地点=Groups、自定义分组=Folder、管理分组=Settings），选中态变成**浅湖蓝底**（`ShipperTeal.copy(alpha = 0.12f)`）+ 左侧 4dp 湖蓝竖条 + 图标与文字都染湖蓝；「管理分组」上面多了**一条分隔线**（`HorizontalDivider`，上下 4dp），它自己仍然是"跳去另一个界面"的那一格。⛔ 这一列**不画对勾**（宽度只有 112dp）。从「线路分类」抽屉看过去，两处已经是同一套长相与同一套语义色。

### Must Preserve

```text
- 历史订单 / 历史金额 / 已冻结的 Pricing Fact
- 历史 Provenance / Audit / Ledger
- 权限
- API compatibility
- 本事项特有的：MasterRail 的行为（key / onSelect / 选中谁 / 行高 / 整列底色 / 副标题）；
  CategoryDrawer 那一列的长相与对勾；另外 3 个落点的传参；地址与分类数据
```

### Blast Radius（L0～L3）

**L0 —— 展示层。** 改动全部落在 `ui/common/Components.kt::MasterRail`（渲染）＋ `ui/shipper/OrderCreateScreen.kt`（传参与图标表）两个文件里，是像素级的画法变化：不写库、不发新请求、不改契约、不碰钱与账本。同一个 `MasterRail` 的另外 3 个落点会跟着换选中底色（它们不传 icon / dividerBefore / accent），这是"只有一份实现"的既定代价，不构成 L1。
