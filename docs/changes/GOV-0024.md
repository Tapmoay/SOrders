## ① 六问

1. **我要解决什么问题**：AI 侧没有一句「你的读范围到哪儿为止」。目录（`docs/ai/ai_read_catalog.json` 与 `AiReadCatalog.kt`）只是**喂给模型的清单**，模型被问到范围外的表时仍会去试（试完 403，再换个问法试）。同时 `_tools/ai/_check_role_parity.py` 报 **3/17 红**（声称货主/派单员能读到自己角色不该有的端点）。
2. **当前用户/业务流程是什么**：三种角色（派单员 / 货主 / 批发商货主）。AI 的读能力由 `AiReads.forRole(role, member)` 现算 —— 工具说明、enum、提示词清单都从它来；执行前再过 `AiReadService.kt` 的 `AiReads.allows(role, action.action, enabledModules())`。货主真正能读什么，**只由后端授权决定**（`backend/app/core/rbac.py` 的 `ROLE_PERMISSIONS` 与各端点的 `require_permission` / `DispatcherUser`）。
3. **哪个现有事实或能力会发生变化**：① 提示词里多一段**与目录同源**的范围声明（模块中文名 + 张数，现算）；② `_check_role_parity.py` 的静态解析精度提高（不再把共用处理器类的邻座动作算给本动作）；③ 多两份脚本：`_tools/qa/_check_ai_role_read_scope.py`（52 项）与 `_tools/qa/_reverse_verify_ai_role_read_scope.py`（8 条注入）。

### 判据写宽的两层机制（这就是那 3 条红的根）

## ④ Behavior Contract

- **Input**：`AiReads.forRole(role, member: Boolean): List<ReadAction>`（角色 + 是否批发商货主）—— 提示词与工具说明拿的是**同一份**列表。
- **Output**：`brief()` 在「查数据（只读）」之后多拼一段（`AiReadScope.rule(modules, tableCount)`）：
  `· ⛔ 你只能读上面这几块里的东西。范围外的一律不要尝试、也不要猜（后台会直接拦住，换一种问法也一样）。` ／ `· 范围就是这几块：<模块中文名>（共 N 张表）。` ／ `· 读不了的东西 = **没有授权给你**，不是「系统里没有」；被问到就直说这件事不归你看，别绕。`
- **Success**：模块中文名与张数**逐字等于** `AiReadScope.cnOf(AiReadScope.modulesOf(AiReads.forRole(role, member)))` 与 `reads.size`（判据 §2 钉死；单测 `AiRolePromptTest` 那两例再钉一遍）。
- **Failure**：目录为空 / 张数低于反空转下限 ⇒ `rule()` 返回 `null`、这段**不说话**（宁可不声明，也不说一句错的）；判据 §0 的下限 = 目录 ≥50 行、模块 ≥10、张数 ≥30、货主 ≥15。
- **Boundary Cases**：`unknown` 角色没有任何动作 ⇒ 不拼这段（单测钉着）；批发商货主与普通货主共用同一条生成路径（只有 `forRole` 的第二个实参不同）。
- **Side Effects**：提示词变长几行；⛔ 不动确认卡、不动写闸门、不动动作清单与工具 enum。
- **Authorization**：基准是 `backend/app/core/rbac.py::ROLE_PERMISSIONS` 与各端点的 `require_permission` / `DispatcherUser`；AI 侧执行前那道门仍是 `AiReadService.kt` 的 `AiReads.allows(role, action.action, enabledModules())`。
- **Compatibility**：Compatible —— 后端契约零变化；这段声明是**附加文本**，旧客户端不读它也不受影响；目录未改 ⇒ 旧版 App 的裁剪结果与新版一致。

## ⑥ CHG 专章

这一节按「改动前后 + 必须保住什么 + 爆炸半径」写（虽是 GOV，但提示词侧确实变了）。

### Before

提示词里 AI 只知道**能做什么**（动作清单）与**界面上有什么页面**，**没有一句说读的范围到哪儿为止**。被问到范围外的表，它会去试 → 后端 403 → 它换个问法再试（用户点的就是这个洞）。

### After

`brief()` 里紧跟「查数据（只读）」之后多一段由目录**现算**的声明：⛔ 范围外一律不要尝试 / 也不要猜；范围 = 模块中文名（共 N 张表）；读不了 = **没有授权给你**，不是「系统里没有」。执行前那道门（`AiReads.allows`）不变 —— 声明只是**让模型不去想**，门才是**兜底**。

### Must Preserve

后端授权（`backend/app/**`）、目录的角色（`docs/ai/ai_read_catalog.json` 未改）、动作清单与工具 enum、确认卡与写闸门、`forRole` 的裁剪语义、API 兼容性、其它会话在改的 `ui/**`。

### Blast Radius（L0～L3）

**L1**：只影响 AI 的提示词文本与判据。L0 的数据/接口/授权面零改动；L2/L3（跨模块、架构级）不涉及。
