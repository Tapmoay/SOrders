## ⑥ CHG 专章

### Before

一条线路的起点 / 终点有**两份定义**：卡片（`ui/common/RouteRail.kt`）里是私有的
`OriginTeal #00BCD4` / `DestOrange #F5A623`，表单（`AddressScreen.kt`）里是
`InventoryTeal #00A8A8` / `MoneyOrange #FF9500` —— 同一件事在两个地方配了两个色。
另有四处「借色」：电话图标三处写死 `Color(0xFF00B578)`（别处用 `MgrGreen`）、
「新增联系人」用 `MgrGreen`（人应当湖蓝）、地点「分组」用商品管理的 `ProductPurple #8455E6`、
地点「备注」用「已撤销」的 `#8A8A8E`。文字那边：常驻标题 12 字与 11 字，
`ImageStrip` 的说明句是裸 `Text`（提示开关关掉也照样占位）。

### After

起点 / 终点的定义只剩一份，在 `ui/theme/Color.kt`（`OriginTeal` / `DestOrange`），
卡片与表单都 import 它；电话一律 `MgrGreen`、人一律 `ShipperTeal`、
地点「分组」`ShipperTeal`、地点「备注」`MaterialTheme.colorScheme.outline`。
本页 `Color(0xFF…)` 字面量清零。常驻标题压到 8 字内，说明句走 `Hint(`（跟着提示开关走）。

  三档标签顺序、切档清空关键词、线路占位语（_check_ai_guardrails.py:4074 的锚点、
