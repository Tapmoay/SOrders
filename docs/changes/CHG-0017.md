# CHG-0017 · 车辆管理页按设计规范重做（第 2 批：抽屉表单 —— 白卡分组、选取器改下拉、属性一项一行）

> 第 2 批只治「新增 / 编辑车辆」那个抽屉里的表单。CHG-0016 的 Known Limitations 把这块明确留给了本批：
> 抽屉里当时还是**手拼**的一套 —— 一个描边输入框 + 一堆裸 `Text("车型")` 小标题、车型与车身型式是横排点选 chips、

> 规范 §5.0 写的是「分组一律白卡」、§5 写的是「从若干项里选一项一律用下拉」—— 本批就是把这三点落到这一屏。

① 五件事，还是「同一个事两种画法」那一类（CHG-0016 治了列表与卡片，这一屏当时整块留着）：

1. **抽屉里的表单没有分组**。三个主题（车辆 / 车身与属性 / 司机与状态）全靠 `Spacer` 隔开、
   标题是裸 `Text("车型", style = labelLarge)`，唯一的输入框还是**描边**的 `OutlinedTextField` ——
   规范 §5.0 的卡片形态是白卡，地址页那三个抽屉早就是白卡了，只有这一屏不是。
2. **两个选取器是横排点选 chips**。车型三档、车身型式五档（含「未设置」）各是一个 `Row { PickChip(...) }`；
   规范 §5（:1377）写死了「需要从若干项里选一项 —— 一律用下拉」。真机上五档在窄屏换行、
   「未设置」被挤成两行（见 `_tmp/v1_5554_sheet.png`），选中项与未选中项只靠 8dp 间距区分。
3. **车辆属性两列一行**。`attrsFor(vm.draftBody).chunked(2)` 把「车高(米)」「车宽(米)」「净重(吨)」
   「载重(吨)」「容积(方)」挤在半栏宽里，标签动不动折行；而且两列排布会让「车高」和「车宽」看起来是一对、
   把「净重」和「载重」当成同一件事（一个影响算钱、一个只是台账）。
4. **抽屉没拉满、键盘不顶起**。`_check_sheet_form_pages.py` 的欠账表里挂着这条：「新增 / 编辑车辆」表单
   `有 verticalScroll，缺 fillMaxHeight` —— 大屏上抽屉只开到内容高度，保存键悬在半空。
5. **保存键是黄绿底白字**。CHG-0016 给「保存」换了 `containerColor = VehicleAccent`，但字色还是
   `ButtonDefaults` 的白 —— 黄绿 `#CDDC39` 上白字的对比度约 **1.4:1**，真机上「保存」两个字几乎看不清。
   同一个黄绿在新车 FAB 上早就是深橄榄字（`OnDriverLime`），只有这里漏了。

② 派单员进「工作台 → 司机管理 → 车辆管理」→ 点开某张卡片（或点黄绿 FAB 新增）→ 抽屉里从上到下填：
车牌号（必填）→ 车型（下拉）→ 车身型式（下拉，决定下面能填哪些属性）→ 逐项填车辆属性（没量过的留空）
→ 绑司机（可搜）→ 启用开关 → 保存；要反悔就点「取消」（抽屉上还有 ✕）。

页脚变成「取消 / 保存」两键并列并把保存键的字色显式写成 `Color(OnDriverLime)`。

④ 不能变：车型取值表 `VEHICLE_TYPES = ("trailer" 挂车 / "large" 大货车 / "small" 小货车)`
（**计费口径**，`_check_vehicle_attrs.py` 逐字符钉着，`models/user.py::resolve_billing_mode` 还靠 `trailer` 分派件），
`body_type` 与属性表的两处唯一口径（`attrsFor(vm.draftBody)` / `capacityText(v.attrs)`）、
只停用不删除（车牌要留在记账与油耗的历史里）、绑司机仍然只在抽屉里（嵌套弹层会闪）、

`vm.sheetError` 一份口径（错只画一处）、后端 / DTO / 迁移 / 权限 / 审计。

⑤ **PRESENTATION**（改的是这一屏的画法与控件形态，不动任何事实、字段、端点、权限）。

## ⑥ CHG 专章

### Before

`VehicleEditSheet` 是一个 `Column`：`.fillMaxWidth().padding(...).verticalScroll(...)`（**没有** `fillMaxHeight` / `imePadding`），
里面从上到下是 —— `Spacer(12.dp)` → 裸 `OutlinedTextField(label = { Text("车牌号") })` →
`Text("车型", labelLarge)` + 提示 + `Row { VEHICLE_TYPES.forEach { PickChip(label, vm.draftType == k) { vm.draftType = k } } }` →
`Text("车身型式", labelLarge)` + 提示 + `Row { BODY_CHOICES.forEach { PickChip(...) { vm.setBody(k) } } }` →
`Text("车辆属性", labelLarge)` + 长提示 + `attrsFor(vm.draftBody).chunked(2).forEach { pair -> Row { pair.forEach { 裸 OutlinedTextField(weight(1f)) } } }` →
手写的「绑的司机」可点行（`ExpandMore/Less` + `SearchField` + `DriverPickList`）→ 手写的「启用」行（`Text` + `Hint` + `Switch`）→
`vm.sheetError?.let { Text(it, color = error) }` → `PrimaryActionButton(text = "保存", containerColor = VehicleAccent)`（字色由 `ButtonDefaults` 给白）。
同文件底部还带着 `PickChip` 自己的定义（`Surface` + 选中底色）。

### After

抽屉 `Column` 变成 `.fillMaxWidth().fillMaxHeight().padding(horizontal = 16.dp).imePadding().verticalScroll(rememberScrollState())` +
`verticalArrangement = Arrangement.spacedBy(14.dp)`；主体是三张 `FormGroup` 白卡：

1. **车辆**（`Icons.Default.LocalShipping` / `Color(DriverLime)`）：`FormInputRow(label = "车牌号", required = true, placeholder = "如 粤LUB6868")` +
   `ExposedDropdownMenuBox` + `FormPickRow`（`modifier = Modifier.menuAnchor()`，候选 `VEHICLE_TYPES`）+ 一句提示；
2. **车身与属性**（`Icons.Default.Straighten` / `Color(DriverLime)`）：车身型式下拉（候选 `BODY_CHOICES`，`onClick = { vm.setBody(k); bodyMenu = false }`）+ 两句提示 +
   `attrsFor(vm.draftBody).forEach { f -> FormInputRow(attrTitle(f, vm.draftBody), keyboardType = if (f.integer) Number else Decimal, placeholder = "没量过就留空") }` + 型式说明行；
3. **司机与状态**（`Icons.Default.Person` / `Color(NavBlue)`）：`FormRow(label = "绑的司机", …)` + `SearchField`（取默认提示语）+ `DriverPickList` + `FormSwitchRow("启用")` + 停用说明。

页脚是 `Row { OutlinedButton("取消", weight(1f), height(48.dp)); Button("保存", containerColor = VehicleAccent, contentColor = Color(OnDriverLime), weight(1f), height(48.dp)) }`，
表单的错由 `FormErrorLine(vm.sheetError)` 画，抽屉底部留 `Spacer(Modifier.height(24.dp))`；本页的 `PickChip` 定义已删除（`PickChip(` 出现 0 次）。
