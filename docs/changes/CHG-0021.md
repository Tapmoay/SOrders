# CHG-0021 · 记账页「这一笔记给谁」抽屉：头段不再钉死，整段只留一个滚动容器（表单抽屉欠账表清零）

> 派单员「工作台 → 账本管理 → 订单账 → 记账」这一页（`ui/dispatcher/LedgerCreateScreen.kt`）的选货主抽屉，
> 是判据 `_tools/qa/_check_sheet_form_pages.py` 的**表单抽屉欠账表上一行**（也是最后一行）。
> 它原本是「头段（标题 / 直接填名字 / 说明 / 搜索框）**钉死**在抽屉顶部 + 只让名单滚」，
> 名单用的是 `LazyColumn`。欠账表那句归因（「有 `fillMaxHeight(0.88f)`，缺 `verticalScroll`」）**本来就不准**：
> 列表外面再套 `verticalScroll` 会**直接崩**（列表没有高度上限），所以这一页不是"忘了加滚"，而是**形态**问题 ——
> 钉死的头段在小屏或键盘弹起时把名单压到几乎没有，而它自己又滚不动。
> 本批把头段也变成列表的 `item`：**整段只有一个滚动容器**，与账户管理 / 运费模板 / 地址与联系人那三个抽屉同一形态。
> **后端、DTO、权限、审计一行不改**。

## ④ Behavior Contract

```text
Input          点开「这一笔记给谁」（那一行本身或右边的「选择」）。
Output         一个从底部拉到最上面的抽屉：标题「这一笔记给谁」/ 直接填名字的框 + 一句说明 / 搜索框 /
               已注册货主（N）名单（或加载态、或"没找到"）/ 用过的临时货主（未注册）那一段 / 底栏「清空」「完成」。
Success        整段（含头段）可以一起滚：往下滚时头段跟着走，滚到底看得见「用过的临时货主」与底栏两个按钮；
               点某一行选中它并把名字显示回「这一笔记给谁」那一行。
Failure        搜索失败 / 名册拉取失败沿用既有路径（`vm.shipperSearching` 的加载态 + 既有错误提示），
               本事项**不**新增任何失败分支；失败时不改变已选中的货主（不产生半截状态）。
Boundary Cases ① 名册 41 人（实测）时，滚到底仍能看见底栏；② 名单为空时"没找到"那一句也在滚动区里；
               ③ 名册被截断（超 500）时那句提示同样在滚动区里；④ 键盘弹起时输入框不被顶出屏幕（整段可滚）。
Side Effects   无（不写任何持久化状态；抽屉开关仍是 `vm.showShipperPicker` 一个内存态）。
Authorization  沿用既有权能（这一页本来就只有派单员/有记账权的人进得来），本事项不新增权限点。
Compatibility  **Compatible**：不改接口、不改 DTO、不改路由，界面形态变化对后端零影响。
```
