后端、权限、状态机、账本、通知与 outbox 的形状全部不变；其它三处 `EditHint(`（收货人 / 下单人 / 备注）与商品明细编辑未动。
本单唯一需要点名的风险是**"坐标成为派单员可改字段"**：坐标报错司机就会开错地方 ⇒ 两道防线（保存前的 fail-closed 闸 ＋
文字改了坐标没换的橙字提醒）＋ 一条已知缺口（审计里不记坐标，见 §⑨ Known Limitations）。
