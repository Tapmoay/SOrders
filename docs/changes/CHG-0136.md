## ① 六问

**① 要解决什么**：用户 2026-10-22（先要做"货主自己改单"，随后收回）：
「算了算了，暂时不开这个，就不让货主和批发商自己去改订单信息了。但是我们可以在订单详情下面
加一句提示：**要改订单信息请打电话给派单员**。因为我们派单员要知道他到底要改什么信息 ——
不然他在没收到信息的情况下胡乱改，司机就很难判断到底送什么、送多少、送到哪。」

**② 当前流程**：货主/批发商在订单详情里**什么都不能改**（编辑入口只给派单员），但页面上**没有一句话
说明"那我该找谁"** —— 用户只能猜。

**③ 哪个事实会变**：详情页最下面多一句解释；⛔ 权限、数据、通知**一个字节不动**。

**④ 明确不能变**：
- ⛔ 货主/批发商**没有任何编辑入口**（`canEditInfo` / `canEditLines` 仍然只给派单员）；
- ⛔ 不新开接口、不改权限、不动通知与语音；
- ⛔ 这一句**不是按钮**（点了也拨不出去：派单员是谁因单而异）。

**⑤ Core / Extension**：PRESENTATION（L0）。

**⑥ 证据**：判据 6 项 + 真机截图。见 ⑦ ⑧。
