  **答**：① 历史订单的「司机应得」（`driver_pay.pay_for_order` → `freight-settlement` 返回的 `pay_total`）与「货主运费合计」（`freight_fee`）—— 回滚不改变任何一笔历史金额，也不改变它们**是两个数**这件事；② 历史运费结算单（司机结算（按月）那一页里的草稿/已确认/已付款记录，如截图 08 的 `Driver · 2026-09 · 按单 ¥198`、`对账探针司机 · 2026-09 · 已付款 ¥675`）—— 它们由后端与数据库定义，与本页从哪个入口进无关；③ 历史账本流水与已冻结的定价事实（`ledger` 流水、`pricing` 事实）—— 本单只读这一页，从不写；④ 历史「待定价」名单（那些 `freight_fee IS NULL` 的已送达单，截图 03 的「还有 22 单」）—— 回滚不会让任何一单的定价状态发生变化。
