## 1. 项目定位

- **形态**：面向货主、司机、派单员三端的 **Web 应用**，响应式布局，**重点优化手机端**。
- **价值主张**：减少人工沟通、订单与账目数字化可追溯、司机在途可操作（导航、拍照、离线）。

---

## 2. 三大角色 — 核心职责

### 2.1 货主（用户）

| 维度 | 说明 |
|------|------|
| **核心职责** | 下单、在允许状态下撤销、跟踪订单、维护常用地址与联系人、查看个人账本并可导出。 |
| **数据边界** | 仅能访问 **自己的** 订单与账本。 |
| **典型能力** | 多商品行下单（最多 10 组）、高德地图选点、默认地址与联系人库、订单 Tab（全部/派单中/已接单/已送达/已撤销）、详情含单价与小计、已送达可看送达照与水印信息。 |

### 2.2 司机

| 维度 | 说明 |
|------|------|
| **核心职责** | 接收派给自己的订单、导航至收货点、上传带水印送达照（支持离线/批量）、填写可选备注、完成订单。 |
| **数据边界** | 仅 **派给自己的** 未完成/已完成订单；**不可编辑** 订单业务字段。 |
| **典型能力** | 新单 Web 通知 + 语音播报、高德导航、内部备注（与派单员可见）、IndexedDB 离线队列与重试、撤销时列表移除 + 弹窗 + 语音。 |

### 2.3 派单员（管理员）

| 维度 | 说明 |
|------|------|
| **核心职责** | 全量订单与派送管理、单/批量派单、撤回派单并留痕、编辑订单任意字段并记日志、商品价格与货主特殊价、货主账本维护与补录、多维度看板与异常报表。 |
| **数据边界** | **全部** 订单、商品、货主账本；操作需 **留痕**（日志、撤回原因、订单快照等）。 |
| **典型能力** | 全局搜索、派单抽屉（选司机、内部备注图文）、批量派单、撤回恢复「派单中」、价格变动批量通知货主、账本编辑同步货主端、统计下钻与导出。 |

## 3. 关键业务流程

### 3.1 主链路（下单 → 送达）

```mermaid
flowchart LR
  shipper[货主下单]
  pending[派单中]
  dispatch[派单员派单]
  accepted[已接单]
  deliver[司机配送拍照]
  done[已送达]
  shipper --> pending --> dispatch --> accepted --> deliver --> done
```

1. 货主提交订单 → 状态 **派单中**，进入派单员「未派送」池。
2. 派单员 **单订单派单** 或 **批量派单** → 指定司机 → 状态 **已接单**，通知司机。
3. 司机在未完成列表处理：导航、上传照片（水印：时间+地点）、可选备注 → **完成订单**（至少一张照片）→ **已送达**，通知货主与派单员。

### 3.2 撤销与撤回分支

- **货主**：仅在 **派单中** 可「撤销订单」（二次确认）。
- **派单员**：**未派送** 可撤销订单；若已派给司机，需先 **撤回派单**（填原因、记日志与快照）→ 订单回到 **派单中**；司机端订单消失并语音/弹窗提示。
- **日志与追溯**：派单员编辑订单、撤回派单等需可追溯（操作人、时间、原因、快照等）。

### 3.3 价格与账本联动

- 商品 **默认价** + **货主特殊价**；变更后可选择 **批量通知** 相关货主（消息中心 + 已读）。
- 派单员可 **改账本字段**（数量、单价、总价）及 **补录**；变更需 **同步到货主端订单详情与账本**。
- 货主端支持按年月筛选与 **Excel/PDF 导出**（导出结果经消息中心推送下载链接）。

### 3.4 跨端通用能力

- **消息中心**：系统通知、订单状态、提醒；已读/全部已读/删除；重要事件可配合语音。
- **实时通道**：WebSocket + 消息队列；断线重连后补拉未读；关键状态可服务端补发。
- **性能约定**：长列表虚拟滚动、图片懒加载、路由级代码分割、常用字典类数据本地缓存（localStorage/IndexedDB）。

## 5. 推荐技术栈与非功能约束（待需求第 5–8 节定稿后对齐）

以下内容在 **requirements.md 第 5–8 节缺失** 时作为实现默认；定稿后应合并回主需求文档。

### 5.1 与需求 3.4 已对齐的约束

| 类别 | 约束 |
|------|------|
| 实时 | WebSocket + 消息队列；断线重连；关键消息补发 |
| 前端性能 | 虚拟滚动、图片懒加载、路由代码分割、localStorage/IndexedDB 缓存 |

### 5.2 推荐落地选型（可替换）

| 层级 | 建议 | 说明 |
|------|------|------|
| 前端框架 | Vue 3 / React 18 + TypeScript | 响应式 + 组件化；与虚拟滚动、路由分割生态成熟 |
| 构建 | Vite | 与代码分割、按需加载配合良好 |
| UI | 移动端优先组件库（如 Vant / Ant Design Mobile） | 贴合需求中的列表、Tab、抽屉 |
| 地图 | 高德 JS API / URI 唤起 App | 选点、Web 导航；密钥见 [INTEGRATIONS.md](./INTEGRATIONS.md) |
| 后端 | Node（Nest/Fastify）或 Go/Java 等 | 需 REST + WebSocket、异步任务、文件存储 |
| 实时 | WebSocket + Redis Pub/Sub（或 RabbitMQ） | 解耦推送与业务实例 |
| 持久化 | PostgreSQL / MySQL | 订单、账本、审计、消息 |
| 对象存储 | S3 兼容或云 OSS | 送达照片、内部备注图 |
| 导出 | 异步任务生成 Excel/PDF，上传 OSS 后消息中心发链接 | 与需求 3.1.4 / 3.3.4 一致 |

### 5.3 非功能基线（建议）

- **认证**：JWT 或 Session + Cookie；三端角色声明在 token 或会话中明确区分。
- **安全**：HTTPS；上传 MIME/大小校验；派单员敏感操作依赖服务端二次校验与审计。
- **可用性**：司机端离线队列与重试；WebSocket 指数退避重连。
